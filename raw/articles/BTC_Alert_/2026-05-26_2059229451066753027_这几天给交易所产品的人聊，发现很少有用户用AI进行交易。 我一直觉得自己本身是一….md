这几天给交易所产品的人聊，发现很少有用户用AI进行交易。

我一直觉得自己本身是一个好的交易员，AI只是你一个提高效率的工具而已，而不是用AI就可以赚钱。

你需要去部署

你需要去训练

你需要让AI了解你的意图

你需要更加智能的sop去执行他。

这一些让你很难入门去选择ai去交易，也只能停留在多空而已。

如果你真想拥抱AI，并且用低成本的去尝试的话，你可以试试CREAO AI组织的交易赛：

你不用花钱就可以参与一场基于 真实市场数据环境的模拟交易赛事。CREAO 也是首个提供了让用户能通过对话来自定义交易策略并让 Agent 自动执行的 AI Agent 产品。

通过与 CREAO AI 对话构建自己专属的agent，然后用7天的事件去自动的执行他。（赛前你可以多次调试，执行不可修改）

如果你是猛男，项目方会给你500u的体验金，你的策略好可以瓜分10000刀的奖池。

如果你不大行，也可以在不用花token的情况下体验一下AI交易，积累经验。

每位参与者对应 1 个公开 X 身份。

当然你可以进行更加高级的玩法，进行对敲，我觉得按照官方公布的规则是在允许范围之类的。

比如做原油和btc的价格的对敲（本次参赛的标的只有btc和eth）

由于比赛结束后也无法出金（赚的钱拿不走），你对敲的基础在于你想打榜。

报名步骤见和其他注意见引用推文：

1. 连接自己的 X 和 Discord

2. 注册本次活动专用的交易所 Demo 账户，并提交 Demo 账户的 UID

3. 克隆官方提供的原初交易 Agent （官方提供的默认 Agent 交易策略是做空 ETH）

4. 快速配置交易所的 API Key、API Secret、API passphrase（到这一步需要等交易所官方发 API 信息邮件，需要一点时间，收到邮件后再往下）

5. 完成运行验证，确保 Agent 调用成功

6. 进行 Agent 的对话调试与完善（一键对话调整迭代，方便快捷）

7. 完成调试后锁定报名资格
