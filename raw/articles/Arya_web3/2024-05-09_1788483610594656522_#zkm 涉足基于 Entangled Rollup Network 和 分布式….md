#zkm :涉足基于 Entangled Rollup Network 和 分布式序列器技术的BTC L2赛道
#ZKM 成功完成了由 #OKVenture 领投的500万美金Pre-A轮融资，Amber Group、P2 Ventures、https://t.co/RPIB6h6Ebx、Leland Venture等机构跟投，目的是推出一种基于 zkVM 和分布式序列器的技术，用于扩展比特币的第 2 层网络，基于 Entangled Rollup Network 在 L2 上保护原生 BTC 资产。
在本次香港举行的 Bitcoin Asia 大会，ZKM 举办了“比特币龙之地节”活动，联合创始人兼 CEO Kevin Liu 讨论了如何让通用 zkVM 实现网络效应，指出几个核心思想：
1、要实现网络效应，除了建立出色的技术外，公司还必须擅长业务发展，与潜在合作伙伴互动，并鼓励他们在其堆栈上构建；
2、他强调了区分度的重要性，并提到了 Optimism 的成功路径作为一个案例研究；
3、在面对激烈竞争的环境中，他认为灵活性和适应性是成功的关键；
4、详细介绍了 ZKM 的 Entangled Rollup LightPaper，该文件详细介绍了他们设计的互操作性机制，以及他们如何将其技术应用于扩展比特币的第 2 层网络，并提供了本地安全性和可持续收益作为关键特性。

#ZKM 涉及到两项核心技术 Entangled Rollup Network 和 分布式序列器技术，前者解决了 BTC L2 资产的安全性和金融衍生收益的问题，后者解决了 BTC L2 的批量交易问题。
