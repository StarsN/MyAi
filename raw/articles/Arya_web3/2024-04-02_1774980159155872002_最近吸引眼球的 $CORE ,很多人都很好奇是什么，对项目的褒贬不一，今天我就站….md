特别声明，本篇文章不作为投资建议，更不是广告，存粹是内容分享。

$CORE :L1+EVM+BTC算力抵押

一、项目定位
作为一条支持EVM的公链，和BTC结合，允许 BTC的矿工将BTC算力质押到 $CORE 的验证 节点上，弥补BTC挖完以后的问题，是对BTC矿工的补偿。
二、项目介绍
Core DAO 是 EVM 兼容的 L1 公链。Core 是 Geth 代码库的演变，利用 BSC 团队所做的改进，通过硬分叉增加了更大的吞吐量和更便宜的交易费。CORE 是一种不会引起通货膨胀的加密货币，旨在通过完全去中心化的方法自动执行获利策略。Core能够保持去中心化，而不会出现传统 PoW 共识系统中出现的性能折衷。
和其他 L1 相比，Core DAO 的优势：核心区块链基于 Satoshi Plus 共识——PoW 和DPoS（委托 BTC 算力和委托 CORE 质押）的组合运行。 这种组合使核心区块链
具有其他 L1 的可扩展性和安全性，并增加了只有比特币的 PoW 才能提供的去中心化。 通过比特币 PoW 去中心化，结合 EVM 兼容性和治理。
三、技术亮点
Core 采用 SATOSHI PLUS 共识机制，结合了工作量证明（PoW）和委托权益证明（DPoS）。该机制旨在确保链的安全性和可扩展性。
• Core 可作为第二个比特币区块奖励来维护比特币网络，为比特币矿工提供奖励。
• 开发者可以在 Core 上轻松部署和运行以太坊 dApp。
• Core 基于 SATOSHI PLUS 共识，结合了 PoW 和 DPoS 特性，提高了区块链的吞吐量和交易成本效益。
四、Core DAO 生态建设
其实是有生态的，因为这是一条兼容EVM的公链，直到我查找资料才了解到原来已经有生态落地了。
Layerzero —跨链互操作协议： LayerZero 是一种互操作性协议，它使用一种新技术使不同的区块链网络更容易相互连接。LayerZero 为可扩展、安全和去中心化的跨链互
操作性提供了框架。通过将各种链连接到一个平台和接口，多链应用程序可以方便地通信、转移数字资产并达成共识。Core 与 LayerZero 的集成是快速扩展用例和开发
的早期机会。LayerZero 此前宣布完成 1.35 亿美元 A+ 轮融资，由 FTX Ventures、红杉资本与 a16z 共同领投，Coinbase Ventures、PayPal Ventures、Tiger Global
和 Uniswap Labs 等参投，投后估值为 10 亿美元。
LFG Swap —Core 上首个 DEX： LFGSwap 原是 ETHW 链上的头部 DEX，曾经创造了1 天达到一千万美金 TVL 的傲人成绩， LFGSwap 从原本在 ETHW 链上的 DEX（去中
心化交易所）迁移到 Core 链上。LFGSwap 是一个社区驱动的组织，他们致力于创新，并将多种去中心化市场和工具整合在一起，以打造一个与众不同的去中心化交易所，并具有 DAO 属性，为用户提供更有趣的体验。迁移到 Core 链上将加强 LFGSwap ，CoreDAO 之间的合作，并为两个社区带来互惠互利的机会。这次迁移对 CoreDAO、
LFGSwap 和用户都是有利的，将为 Core 带来更多原生加密货币用户，并为 LFGSwap提供更大的社群基础，最终促进两个社区的发展。
Elementwallet—Core 上首个钱包： elementwallet 是为 Core network 构建的第一个钱包应用，作为访问 Core 网络的第一个也是主要的接口，Element 将从加密钱包功能开始，使 Core 参与者能够发送、接收和抵押 CORE 代币以及许多其他功能。最终，随着 Core 和 Element 的共生发展和扩展，Core 协议将可以通过 Element 轻松访问。
五、相关合作
加密矿企 Core Scientific 宣布与 CoreWeave 签订多年合同，提供高达 16MW 的数据中心基础设施，以支持 AI 和 HPC 工作负载。该合同的潜在收入超过 1 亿美元，标志着 Core Scientific 在奥斯汀的托管业务的扩展，并将支持 CoreWeave 的 GPU 计算需求。
截至 2024 年 1 月，Core Scientific 在五个美国州共运营七个数据中心，总运营容量达到 724MW。
