# 壳价值

**定义**：一个代币的市场价值不由"合理估值"或"Utility"决定，而由其作为庄家理财工具的"壳"价值决定——取决于筹码集中度、上币覆盖面和团队资金储备。

📖 **来源追踪**：
- [[@thecryptoskanda]] — PUMP估值分析 (2025-07-09)：正式提出壳价值三要素
- [[@thecryptoskanda]] — $ADA $XRP $LEO 长盛不衰分析
- [[@thecryptoskanda]] — EOS 弃盘批评：「如果那40亿用来坐庄操盘，今天至少世界500强」

🔄 **演变历史**：
- 萌芽：对高FDV神币（ADA/XRP/LEO）为什么"没有utility却长盛不衰"的困惑
- 成形（2025-07）：提出壳价值 = 上所大满贯 + 筹码集中 + 现金储备
- 延伸：将壳价值理论应用于PUMP估值辩护

📊 **交易应用**：
1. **选币过滤**：高壳价值币 > 低壳价值币——前者庄家有动力维持价格
2. **做空禁区**：壳价值高的币不做空（庄家有无限资金维护壳价值）
3. **波段思维**：壳价值币是庄家的理财产品，顺势波段而非价值投资
4. **崩盘信号**：壳价值破坏 = 上所被下架/团队抛售/现金储备耗尽
