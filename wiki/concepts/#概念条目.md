## [[宏观交易]]

**定义**：以宏观经济数据、政策变化、地缘事件为核心判断依据，确定资产方向性走势的交易方式。

**来源**：
- @BTC_Alert_ 大量推文（2023.03 ~ 2026.05）

**演变**：
- 早期（2023）：以美联储加息/降息为核心
- 中期（2024）：加入地缘博弈（日元、关税、大国关系）
- 近期（2025-2026）：三层博弈模型（政策制定者→机构→散户）

**交易应用**：
- 方向判断：宏观→中观→微观三层推导
- 仓位决策：宏观确定则大仓位，不确定则等待
- 对冲：用黄金对冲美元信用风险

**关联概念**：[[降息交易]] [[关税交易]] [[三层博弈模型]]

## [[降息交易]]

**定义**：围绕美联储降息周期进行的交易布局，核心是判断降息路径和节奏。

**来源**：
- 2024.07.28《下周超级央行周，宏观交易的重点在那里》
- 2024.08.22《宏观交易已经迎来降息前最关键的时刻》
- 2025.08.14 降息交易系统性思考

**演变**：
- 区分防御性降息（硬着陆）vs 主动降息/鹰派降息（软着陆）
- 后者对资产估值的影响与前者截然不同

**交易应用**：
- 降息→美元贬值→黄金/加密上涨
- 但需判断资本流向（是否可控）
- 结合关税等其他政策判断

**关联概念**：[[宏观交易]] [[三层博弈模型]] [[黄金对冲]]

## [[对手盘]]

**定义**：每笔交易中站在你对面的参与者（庄家、做市商、套保盘、散户），分析其动机和成本是交易决策的核心。

**来源**：
- @BTC_Alert_ 几乎所有交易推文的核心概念
- 2025.07.16《$PUMP 盈利7w刀的复盘》

**核心应用**：
1. 识别对手（庄/散户/套保）
2. 计算对手成本
3. 预判对手行为（建仓/拉升/爆空/出货/撤退）
4. 站在庄的一侧

**关联概念**：[[庄家博弈]] [[OI分析]] [[流动性分析]]

## [[OI分析]]

**定义**：通过持仓量（Open Interest）变化判断资金流向和庄家意图。

**来源**：
- @BTC_Alert_ 反复使用的核心指标

**应用维度**：
| 维度 | 信号 |
|------|------|
| OI 缓慢积累 + 价格横盘 | 庄在建仓 |
| OI 爆发 + 价格拉升 | 庄在启动 |
| OI 下降 + 价格横盘 | 资金退潮 |
| OI 暴涨 + 价格下跌 | 空头入场 |

**关联概念**：[[对手盘]] [[庄家博弈]] [[流动性分析]]

## [[IP估值]]

**定义**：将名人币/Meme币视为IP资产，用类比估值法（参考doge/pepe模式）评估其价值。

**来源**：
- 2025.02.23《复盘：涉及大盘 $TST $TRUMP $shell》

**核心框架**：
1. IP影响力 = 人物在币圈+金融圈出圈影响力形成最大公约数
2. 估值方法 = 类比已成功的IP案例（doge/pepe）
3. 共识分散 = 第二个同类IP只有第一个的20%市值
4. 二次拉升 = IP持续+筹码重新收集

**关联概念**：[[meme交易]] [[庄家博弈]]

## [[筹码结构]]

**定义**：通过分析不同价格区间的持仓分布，判断支撑/压力位的真实性。

**来源**：
- @Murphychen888（摸批哥）的方法论
- @BTC_Alert_ 多次引用并深化应用

**应用**：
- 识别真实支撑/压力（vs 虚假的）
- DCD阶梯挂单的边界条件计算
- 判断当前持仓成本分布是否被破坏

**关联概念**：[[DCD策略]] [[仓位管理]] [[流动性分析]]

## [[盘前对冲]]

**定义**：在新币TGE前通过盘前市场（Aspecta/WhaleMarket/币安盘前）锁定空投利润或进行套利。

**来源**：
- 2026.03.26《再谈交易：如何利用盘前锁住空投利润》
- 2026.03.31《edgex被反撸6w》

**核心策略**：
1. 确认自己有多少币（空投份额）
2. 在Aspecta等M级深度市场做空对冲
3. 判断项目方格局决定交割时机（TGE后2h vs 立即）
4. 避免币安盘前（波动大，"经常给项目方付费"）

**关联概念**：[[空投套利]] [[流动性分析]]

## [[动态修正]]

**定义**：交易中不断根据新信息调整预期和持仓，而非死守单一观点。

**来源**：
- @BTC_Alert_ 的核心交易哲学
- "动态思考动态修正，这tm才是交易。"

**应用**：
- 不是"看多少"，而是列出持仓和平仓的条件
- 条件改变 → 操作改变
- 对错不重要，修正速度重要

**关联概念**：[[仓位管理]] [[交易体系]]

## [[三层博弈模型]]

**定义**：
- 第一层：散户/机构在交易数据
- 第二层：大型机构在交易政策
- 第三层：政策制定者在利用市场实现战略目标

**来源**：
- 2025.11.20《以美国经济视角结构宏观交易》

**核心信条**："一切经济政策的目的总是为了政策服务。"
→ 交易员必须站在第三层思考。

**关联概念**：[[宏观交易]] [[降息交易]] [[关税交易]]

## [[流动性分析]]

**定义**：以流动性为核心审视所有交易决策——包括池子深度、订单簿厚度、OI分布、市场承接能力。

**三要素**：
1. **池子深度**：多少钱能推动价格？会自己踩自己吗？
2. **OI变化**：资金在进还是出？庄在布局还是撤退？
3. **基差/费率**：多空平衡状态？有套利空间吗？有介入痕迹吗？

**关联概念**：[[OI分析]] [[对手盘]] [[妖币交易]]
