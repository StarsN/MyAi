# Arya_web3 数据源

  - Alpha Launchpad 上新币是重要信号
  - 币安上币公告是交易触发器
- **OKX（欧易）**：
  - 合约 OI 数据 + 资金费率

### DEX

- BSC: PancakeSwap

## 二、市场数据工具

### 合约数据
- **OI（持仓量）**：判断市场热度，OI 增长 = 资金流入
- **资金费率**：极度负费率 = 做多机会
- **多空比（LSR）**：极端值 = 反向信号（< 0.3 做多，> 3 做空）
- **合约/现货成交量比**：> 3x 确认上涨通道
- **爆仓数据**：查看 MM 意图

### 行情工具
- CoinMarketCap / CoinGecko：市值、排名、基本信息
- Coinglass：爆仓数据、OI 变化、资金费率综合
- TradingView：K 线技术分析

### 链上数据
- **链上筹码分析**：代币持有者分布、大户持仓变化
- **DEX 交易数据**：链上买入/卖出量
- **链上 OG 盘识别**：Meme 币早期监控
