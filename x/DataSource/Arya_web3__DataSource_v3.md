## 一、合约数据指标（按使用频率和深度排序）

### 1.1 核心盘面六维指标

| 指标 | 用途 | Arya原文信号 | 出处 |
|------|------|------------|------|
| **OI（持仓量）** | 庄建仓/撤退识别、妖币判断、真假辨别 | OI↑+价↑=真趋势；OI↑+价↓=洗盘诱空；OI大+爆仓极小=造假 | [2026-03-22] |
| **OI vs MC比** | 妖币结构判断 | OI>MC市值→妖币潜力 | [2026-05-17] |
| **多空比（LSR）** | 极端反向 | 极端值→反向操作；0.27（79空21多）→爆空 | [2026-04-11] |
| **资金费率** | 做多/做空信号 | 极度负费率=做多；负费率变小=警惕庄平多；MC>1亿高估→开空等负费率变大平 | [2025-04-29] |
| **合约/现货成交量比** | 通道确认 | >3x→上涨通道确认 | [TF] |
| **合约成交额（24h）** | 热度+趋势判断 | 持续放大→妖币趋势；判断MM操盘活跃度 | [2026-06-07] |

| 数据 | 用途 | 案例 | 出处 |
|------|------|------|------|
| MM平均多单成本 | 入场安全边际 | $UB庄多单成本0.125u；$BILL庄多单成本0.1u | [2026-05-24] |
| 庄空单建仓成本 | 判断下跌趋势确认 | 空单一直没撤+盈利越来越多=庄出货+建好空单 | [2026-05-22] |
| 多空建仓价格K线叠加 | 判断庄成本和趋势方向 | | [2026-05-22] |

| 爆仓数据类型 | 用途 | 判断逻辑 |

| 24h多军爆仓金额 | 判断MM意图：有空军就拉盘定点爆破 | [2026-04-13] |
| 24h空军爆仓金额 | 同上，反向 | |

| 爆仓极小+OI极大 | OI造假判断→庄多空双开 | [2026-03-22] |

### 2.3 庄地址追踪方法

> 「要学会看链上数据，更要找出来庄的地址，尤其是币价下跌的时候，要知道是谁在出货」[2025-07-28]

步骤：
1. 找出做市商主地址（如Wintermute地址）
2. 标记主地址转出的所有子地址
3. 监控每个子地址的买卖行为
4. 统计「清仓地址数 vs 还在持币地址数」
5. 计算已实现利润 vs 未实现利润

## 八、数据使用优先级（v3更新版）

1. **庄的意图** → 项目方/做市商地址是否出货、MM多空单成本、爆仓数据结构、OI真假
2. **合约结构** → OI vs MC、成交量、资金费率、多空比、庄多空建仓价格
3. **链上数据** → 持仓分布、地址追踪、场外流通比例
4. **叙事与注意力** → 赛道轮动、市场热点、阅读量指标（<1万=无人问津）
5. **K线区间** → 顶底差50%-5x→波段入场时机
6. **基本面** → 团队、融资、产品（⚠️权重已在2026年显著下降）

> 「现在币圈的很多项目，都不要看基本面了，就看庄的操盘手法」[2026-05-25]

## 九、关键指标交叉验证矩阵

| 信号组合 | 判断 | 操作 |
|---------|------|------|
| OI↑+价↑+爆仓真实+庄多单成本接近 | 最强做多信号 | 重仓做多 |
| OI↓+价↓+庄空单盈利+链上出货 | 最强做空信号 | 跟空 |
| OI大+爆仓极小+价格横盘 | OI造假，庄多空双开 | 回避 |
| 多空比极端+负费率+OI干净 | 做多信号 | 建多单 |
| 负费率变小+庄平多+现货充值到交易所 | 见顶信号 | 平仓/做空 |
| MC>1亿+资金费率正+高估 | 开空机会 | 等负费率变大平仓 |
