## 九、数据使用优先级（v2 更新）

1. **宏观链条** → CPI/美债/原油/日元的因果串联→定大方向
2. **基差/溢价** → 币安溢价指数+基差变化→多空平仓方向 [v2 新增]
3. **庄控盘判断** → OI vs MC + 筹码集中度 + 基差变化速率 + 护盘行为 [v2 新增]
4. **对手盘分析** → 谁在对面、成本在哪、动机是什么
5. **流动性三角** → 池子深度 + OI 变化 + 基差费率
6. **K 线结构** → EMA200 + 缠论 + 威科夫 + 筹码结构

> 「2H-4H 级别做结构判断，信息出来后再以 K 线理论找接入的机会」[2026-06-05]
