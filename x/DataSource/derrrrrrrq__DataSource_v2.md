## 七、关键监控指标优先级

1. **OI 真伪** → 自研工具剥离假 OI → 确认真实主力方向 [v2 新增顶格]
2. **Wyckoff 阶段** → 吸筹/派发/SC/ST/SOS/SOW 识别
3. **订单簿 imbalance** → market order 消化 limit order 的速度
4. **妖币阶段指标** → 前中期看 OI+Vol，派发期看 Price+MCap [v2 新增]
5. **对手盘蓄水池** → 币安广场 + OI 多空结构
6. **筹码演化方向** → 紧凑化（妖币）vs 分散化（共识币）[v2 新增]
