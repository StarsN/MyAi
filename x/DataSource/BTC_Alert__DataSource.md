## 一、交易所与交易平台

### 主要使用

| 平台 | 用途 | 关键功能 |
|------|------|---------|
| **OKX** | 主战场 | 合约、现货、期权、DCD、信号策略、集合竞价、盘前交易 |
| **币安 (Binance)** | 辅助 | 合约、盘前合约、Launchpool |
| **Aspecta (ASP)** | 盘前对冲 | M 级别深度，支持不爆仓等待 TGE 交割 |

### OKX 核心功能深度使用

- **信号策略**：通过中间商链接 TradingView → OKX，K线/筹码体系交易员可编程自动交易，导出交割单回测
- **DCD（双币宝）**：阶梯套利建仓/止盈，基于筹码结构计算边界条件
- **集合竞价**：盘前与机构拍筹码，识别定价偏差（如 $PARTI 开盘不到 0.3）
- **账户抽象**：跨币种保证金 + 组合保证金，实现戴维斯双向螺旋
- **现货止损卖空**：设置触发价格自动卖出，睡梦中保护现货
- **双压期权**：同时买看涨+看跌，大涨大跌都赚，横盘亏
- **OKX PAY**：U 理财（10000U 年化 10%，超出 5%，活期无上限）

## 二、技术分析工具

| 工具 | 类型 | 用途 |
|------|------|------|
| **TradingView** | 图表平台 | K线分析、策略编程（Pine Script）、信号生成 |
| **EMA200** | 技术指标 | 长期趋势基准判断 |
| **缠论** | 理论体系 | 结构分析（中枢、背驰、级别递归） |
| **2H-4H K线** | 时间框架 | 中期结构判断主周期 |
| **紫色指标** | 自研 | 量价辅助指标，主要用于土狗/Meme 交易 |
| **筹码结构** | 分布分析 | @Murphychen888 的筹码分布法 |

### 紫色指标说明

- 自研量价指标，用于土狗/Meme 币交易
- **小级别**：识别短期量价异动
- **大级别**：过滤"倒钱包"等干扰，判断真实量价
- 已知局限：对土狗止盈和各种倒钱包操作有不足
- 改进方向：扩大级别消除干扰 + 结合叙事预期判断

## 三、宏观数据来源

| 数据 | 来源 | 用途 |
|------|------|------|
| CPI / PPI | 劳工部 | 通胀判断 |
| 非农就业 | 劳工部 | 经济健康度 |
| 美联储决议 | FOMC | 利率方向 |
| 美债收益率 | 市场数据 | 真实利率预期（比美联储讲话更诚实） |
| 原油价格 | 商品市场 | 通胀领先指标 |
| 日元汇率 | 外汇市场 | 套息交易/资金流向 |
| 黄金价格 | 商品市场 | 避险需求/美元信用对冲 |
| 金十数据 | 财经媒体 | 日常数据播报（但有局限性） |

### 宏观分析理念

> "深一点就是看看金十，符合预期涨，不符合就跌。大家都希望从周级别的数据押注宏观带来的上涨，而一切经济政策的目的总是为了政策服务。"

*不只看数据本身，更看政策制定者的动机。*
