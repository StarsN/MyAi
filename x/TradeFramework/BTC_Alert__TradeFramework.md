## 一、宏观驱动的方向性交易

BTC_Alert 最核心的方法论是**以宏观分析确定方向，以技术面选择时机**。

### 宏观分析的三层框架

1. **货币政策层**：美联储利率决议、降息/加息路径、缩表/扩表 → 决定资金面方向
2. **经济数据层**：CPI/PPI、非农就业、GDP、美债收益率 → 验证宏观判断
3. **地缘与政策层**：关税、外交事件、大国博弈 → 识别预期差

> 例：82164 做空 BTC — 从原油→CPI→美债→美联储换帅→访华→日元→EMA200，五层连锁推导，缺一不可。

### 宏观与资产的串联

BTC_Alert 始终将加密货币放在**全球资产配置**的框架中：

```
原油价格 → 通胀预期 → 美债收益率 → 美元指数 → 风险资产（美股/加密）
                                 → 黄金（避险对冲）
日元汇率 → 套息交易 → 美股资金面 → 加密联动
```

**核心信条**："一切经济政策的目的总是为了政策服务"——从政策制定者动机出发，而非表面数据。

## 二、系统性连续交易

### 不是碎片化操作

> "交易是很系统又连续的事情，不要搞断章取义。"

- **每个决策有前置推文可追溯**：建仓理由在之前的推文中已论述
- **交易主线维持数周至数月**：如 3-4 月以 7.8w 为基础制定交易主线，6 层仓位不动
- **不因短期波动改变主线**：除非核心逻辑被证伪

### 交易与复盘闭环

```
建立预期 → 入场 → 持仓验证 → 动态修正 → 平仓 → 复盘 → 优化体系
    ↑___________________________________________________________↓
                        不复盘 = 没有进步
```

## 三、仓位管理与风险控制

### 分层仓位制度

| 层级 | 用途 | 操作 |
|------|------|------|
| 主仓位（6层） | 基于宏观预期的长期持仓 | 不动如山 |
| 剩余仓位（4层） | 抄底/加仓/对冲 | 阶梯挂单（DCD策略） |

### DCD 阶梯套利

利用 OKX 的 DCD（Dual Currency Deposit）策略：
- 基于筹码结构计算边界条件
- 分层挂单，阶梯式建仓/止盈
- 例：BTC 第一层挂 7.3w（筹码结构破坏位）

### 止损原则

- **止损位 = 当初判断加仓的价格空间的点**
- 不止损于恐慌，只止损于逻辑证伪
- 动态调整，不止损后不追

## 四、交易对手盘分析

### 核心问题：谁在对面？

BTC_Alert 在每笔交易前都问：
1. 对手盘是谁？（庄/散户/套保盘/做市商）
2. 对手盘的成本在哪？
3. 对手盘的动机是什么？（建仓/出货/爆对手/测试机制）

### 典型分析案例

**$PUMP 做多决策**：
- 盘前合约持仓 = 市值的 50% → 只有庄能建这么大
- 庄的建仓成本在 50-70，且有力去击穿 3x 套保
- 池子深度 10M → 能决定 600M 合约 OI 的死活
- 结论：庄会拉升爆空 → 做多

**$TRUMP / $TST IP 估值**：
- CZ 和特朗普的 IP 影响力形成最大公约数
- 用类比估值法：doge/pepe 模式的 IP 变现
- 共识分散后短期价值被稀释（第二个只有第一个 20% 市值）
- CZ 狗出来 → 平掉 TST 多单

## 六、动态修正体系

> "动态思考动态修正，这tm才是交易。"

### 不是"看多少"，而是"什么条件下改变看法"

BTC_Alert 从不定死目标价，而是列条件：
- **持仓条件**：庄家建仓成本未被破坏、OI 居高不下、爆空有利可图
- **平仓条件**：项目方回购（左手倒右手）、偏离预期、流动性变化、关键结构破位

### 妖币交易框架（开发中）

- 流动性筛选：排除了会自己踩自己的标的
- OI 积累阶段主力判定：单边建仓 vs 双持
- 基差变化速率监测：有的所基差是被介入过的
- 测试 16 单 ORDI，多空双做，持续优化

## 七、交易心态与纪律

1. **"不要把鸡蛋放在一个篮子"** — 分散配置（现货+合约+理财+套保）
2. **"现货从不卖"** — 长期现货持有，合约只用于方向性博弈
3. **"我从不跳大神"** — 不喊单，只讲逻辑和系统
4. **"拒绝量产"** — 每篇文章都是独立深度思考
5. **"戴套"** — 永远用对冲保护现货敞口（期权双压/现货网格）
6. **"亏了锤JB"** — 亏了就认，但不抱怨，整理情感继续

## 八、新币/空投交易方法论

1. **盘前对冲**：用 aspecta/whalemarket 等盘前市场锁定空投利润
2. **集合竞价判断**：盘前与机构拍筹码，识别定价偏差
3. **TGE 抛压预判**：项目方格局大小决定抛压大小，选择 TGE 后 2h 交割
4. **链上监控**：合约部署、池子创建、代币分发全流程跟踪
