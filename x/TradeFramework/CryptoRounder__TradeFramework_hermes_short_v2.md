## 零、进场前置：大周期位置判断

CryptoRounder 的全部交易决策基于对 BTC 大周期位置的判断。山寨币进场前必须先确认周期阶段。

### 0.1 四年周期定位

> 「每次减半发生在大选年，减半后第二年的第四季度见顶，熊市在中期选举年触底，四个周期几乎都是这样的规律」[2026-05-27]

| 阶段 | 特征 | 操作 |
|------|------|------|
| 熊市后期 | 价格阴跌，媒体说 BTC 死了 | 分批抄底 + sell put 接货 |
| 牛市初期 | 周线 MACD 金叉，趋势形成 | 以休息为主，等待确认 |
| 牛市中期 | 大利好显现 | sell call 被动止盈减仓 |
| 牛市后期 | 上涨衰竭，指标背离 | 定抛 + sell call |

> 「从来没有什么超级周期，你在冬天按下买入键的时候，已是万径人踪灭」[2026-05-27]

### 0.2 关键周期判断指标

| 指标 | 含义 | 出处 |
|------|------|------|
| 周线 MACD 金叉/死叉 | 大趋势转折 | [TF] |
| M2 全球货币供应（前移 90 天） | BTC 中期方向 | [TF/2025-08-11] |
| 隐含波动率(IV)中枢 | IV 中枢下破新低→接近熊市底 | [2026-05-31] |
| 巴菲特指标 > 200% | 市场整体高估警告 | [TF/2026-05-03] |
| CME 缺口引力 | 短期方向参考 | [2026-05-05] |
| MSTR mNAV（溢价/折价率） | 历史最低 0.51=5折BTC→终极底部 | [2026-06-04] |
| 波动性与动能指标（翻红/翻绿） | 红绿转换=牛熊转换先觉信号 | [2026-05-31] |

## 一、进场信号清单（合约可映射部分）

### 1.1 空头拥挤反向

- **资金费率转负 + 持仓迅速增加 + 空头拥挤** → 短期做多强势山寨，止损很近，盈亏比好 [2026-06-05]
- RSI 日线超卖乖离 + 统计学几乎不可能一把下去 → 不宜追空，合约可短期做多 [2026-06-05]

> 「$BTC 资金费率转负，持仓迅速增加，空头开始拥挤，个人短期做多了强势山寨币 $HYPE 和 $WLD，止损很近，盈亏比不错」[2026-06-05]

### 1.2 趋势延续判断

- **熊市旗形 + 斜率走弱** → 较大概率延续下跌 [2026-05-07]
- **15m 趋势破** → 加仓做空山寨（极小比例仓位）[2026-04-12]
- **日线放量突破失败，3-4 根日线回不去** → 假突破概率大 [2026-05-08]

> 「熊旗之后较大概率还是延续下跌。底层逻辑是阶段性触底后市场按一定斜率修复，斜率再次走弱表明市场需求开始不足」[2026-05-07]

### 1.3 BTC-山寨联动

- **HYPE 主力是聪明钱，可参考 BTC 行情** → HYPE 对 BTC 有先行指标作用 [2026-06-05]
- **ZEC 与 BTC 顶部的关联**：ZEC 矿机厂商（比特大陆）曾为 BTC 庄家，ZEC 大涨常对应 BTC 中期顶部 [2026-05-11]

### 1.4 威科夫结构信号

- **威科夫冰线（$84K附近）有效跌破** → 供给胜出，反弹=最后派发/加空机会 [2026-05-10]
- 当前周期有 Strategy 等「空中吸筹」大玩家，威科夫结构仍有效但节奏被拉长 [2026-05-10]

### 1.5 庄家行为参考

- **熊市拉盘** = 主力利用熊市空头流动性 → 应考虑做多而非做空 [2026-04-13]
- **山寨币长期下跌是极大概率** → 极小仓位做空可实现长期高胜率 [2026-04-12]

## 二、否决信号（出现任一 → 不进场/极轻仓）

1. **方向不明（周期冲突）**：15m 与 4h 方向相反 → 震荡，不参与 [v1]
2. **远离关键位**：无布林带/VPVR/威科夫结构参考 → 不进场 [TF]
3. **信息不对称**：走势特征变化快，与主力信息差大 → 止损离场 [2026-04-13]
4. **聊得太大声**：过去经验失效+庄家干预 → 止损/挂止损睡觉 [2026-04-12]
5. **追空恐慌行情**：日线 RSI 超卖乖离 → 不宜追空 [2026-06-05]
6. **裸合约杠杆**：不提倡 [TH]
7. **鱼尾行情**：参与搏杀最后的鱼尾，群体胜率极低 [2026-06-01]

## 三、出场/止盈信号

- 做空山寨：短期出现大回调即止盈 [2026-05-31]
- 预期失效：过去的经验总结在此次失效 → 止损 [2026-04-12]
- 趋势破位：15m 趋势破→加仓，不止盈不止损 [2026-04-12]
- 期权表达：put 建仓在轧空期间进行（不急于一次性满仓）[2026-05-05]

## 五、进场决策速查流程（step-by-step）

```
Step 1 → 判断大周期位置（0.1-0.2）
    ├── 熊市后期 → 分批抄底 + sell put 接货
    ├── 牛市初期 → 等待确认
    ├── 牛市中期 → sell call 被动止盈
    └── 牛市后期 → 定抛 + sell call

Step 2 → 查否决信号（第二章）
    └── 任一命中 → SKIP

Step 3 → 查空头拥挤（1.1）
    ├── 费率负 + OI↑ + 空头拥挤 → 做多强势山寨（极轻仓）
    └── 无拥挤信号 → 继续观察

Step 4 → 查趋势结构（1.2-1.3）
    ├── 熊旗+斜率走弱 → 延续下跌，极轻仓做空
    ├── 15m趋势破 → 加空
    └── BTC 联动山寨信号 → 参考操作

Step 5 → 查威科夫结构（1.4）
    ├── 冰线有效跌破 → 加空机会
    └── 冰线支撑 → 观望

Step 6 → 确认仓位
    └── 极轻仓（<0.1x），止损近，盈亏比好 → ENTER
    └── 否则 → WAIT / SKIP
```
