## 零、进场前置：市场结构判断

进场前先判断当前处于哪种市场结构，不同结构对应完全不同的策略。

### 0.1 市场结构三态

| 状态 | 特征 | 策略 | 出处 |
|------|------|------|------|
| 牛市 | 主力聚集，筹码健康 | 找庄币底部吸筹区，做多为主 | [TF] |
| 过渡期 | 高控筹妖币活跃 | 跟踪妖币操盘，多空灵活 | [TF] |
| 熊市/派发后期 | 筹码派发几波+现货高换手 | 做空高估值新币，不做多 | [TF/2026-06-02] |

> 「不同市场阶段需要完全不同的策略。结构转变后主力重新聚集——盲目做空必亏」[TH]

### 0.2 Wyckoff 阶段快速识别

**吸筹阶段** (做多区域)：
```
SC（恐慌抛售）→ AR（自动反弹）→ ST（二次测试）→ SOS（强势信号）
```

**派发阶段** (做空区域)：
```
PSY（初始供给）→ BC（购买高潮）→ SOW（弱势信号）→ LPSY（最后供给点）
```

> 「大派发后期，别人筹码都派发几波了，还想着拉上来，想多了」[2026-06-02]

## 一、进场信号清单

### 1.1 努力与结果法则（核心量价信号）

| 盘面表现 | 含义 | 方向 | 出处 |
|----------|------|------|------|
| 放量不涨 | 主力在派发出货 | 做空 / 撤离 | [TH] |
| 缩量上涨 | 浮筹已清，主力控盘 | 做多 | [TH] |

### 1.2 OI 结构：真伪辨别（2026 新增核心）

derrrrrrrq 在 2026 年反复强调区分「真 OI」和「假 OI」：

**庄 OI 造假手法**：
- 多空双开 → OI 增加 + 价格下降 + CVD 下降 → 看起来像空头堆积，实际是庄在造假 [2026-05-22]
- 「拉升回来后 OI 基本没降低多少 → 下跌过程中有烟雾弹 OI」[2026-05-22]

**真实 OI 判断**：
- 使用自研工具剥离多空双开的虚假 OI
- 拉升回来后的空头 OI 比拉升前低很多 → 之前的空头 OI 是假的 [2026-05-22]

| 信号 | 判断 | 出处 |
|------|------|------|
| OI↑ + 价↓ + CVD↓ | 庄在做空（快速反应做空信号） | [2026-05-22] |
| 但拉升后 OI 没怎么降 | 之前的 OI 是烟雾弹——庄多空双开制造假象 | [2026-05-22] |
| 拉升后空头 OI 大幅低于拉升前 | 假 OI 已被剥离，之前的空头信号不可信 | [2026-05-22] |

### 1.3 妖币前中后期指标体系（2026 新增）

> 「妖币在前中期 price、mcap、fdv 都不是重点，oi 和 vol 才是重点。oi 代表交易兴趣，vol 代表换手」[2026-05-25]

| 阶段 | 关注指标 | 操作逻辑 | 出处 |
|------|---------|---------|------|
| 前中期 | OI + Vol | ROI 最高，price 低 + OI Vol 高 = 安全 | [2026-05-25] |
| 派发期 | Price + MCap | 价格高 + OI Vol 减少 → 接盘风险倍增 | [2026-05-25] |
| 后期 | 筹码紧凑度 | 妖币越往后筹码越紧凑（vs 共识币越散） | [2026-06-06] |

> 「派发期参与进去，和前期相比赚同样的钱，背后承担的是几倍以上的风险」[2026-05-25]

### 1.4 多空挤压识别

| 挤压类型 | 条件 | 方向 | 出处 |
|----------|------|------|------|
| 多头挤压 | 空头蓄水池满 → 主力拉盘爆空 | 跟随做多 | [TF] |
| 空头挤压 | 多头 OI 堆积 → 主力砸盘爆多 | 跟随做空 | [TF] |
| 短期 AR | 庄空头仓位平仓 + 新多头进场 → 自然反弹 | 短线做多 | [2026-05-28] |

### 1.5 对手盘观测（2026 新增方法）

> 「币安广场是一个比较好的对手盘观测基地」[2026-05-31]

**低市值妖币启动信号**：
```
高换手 + 涨幅大 + OI 低 + 流动性差
→ 对手盘积累 → 挤压一下 → 拉上去
```

### 1.6 主力/散户 OI 分歧

- **多头 follow OI 过多** → 洗盘概率高 [TF]
- **散户极度看空（空头仓位一直不走）** → 主力拉盘爆空的燃料 [2026-05-22]
- OI 变化 + 价格背离 → 主力意图信号 [TF]

## 二、否决信号（出现任一 → 跳过/观望）

1. **杀猪盘**：合约盘口极浅（10wU 仓位插飞几个点）+ OI 双向都大 → 多空双杀，不参与 [TF]
2. **大派发后期**：筹码派发几波 + 现货高换手 → 「玩新不玩旧」[2026-06-02]
3. **链上对敲**：一个地址一直卖，一个地址一直买 → 噪音，非真实供需 [2026-05-24]
4. **OI 造假**：OI↑+价↓+CVD↓ 但拉升后 OI 不降 → 烟雾弹，不按此 OI 方向操作 [2026-05-22]
5. **做空妖币**：妖币做空的 ROI 远不如共识币 → 「妖币越往后筹码越紧凑，越难做空」[2026-06-06]
6. **做空启动前妖币** vs **做空已在运行妖币** → 两种情况资金和筹码天差地别，不要混为一谈 [2026-06-06]

## 五、妖币 vs 共识币行为差异速查

| 维度 | 妖币 | 共识价值币 | 出处 |
|------|------|-----------|------|
| 筹码演变 | 越往后越紧凑 | 越往后越散 | [2026-06-06] |
| 前期指标 | OI + Vol | Price + MCap | [2026-05-25] |
| 后期指标 | Price + MCap | OI + Vol 仍重要 | [2026-05-25] |
| 本质 | 庄聚合筹码强制 3,3 → 博弈涨跌 | 共识驱动 → 价值发现 | [2026-06-02] |
| 做空难度 | 越来越难（筹码紧凑 + 缺对手盘） | 相对容易（筹码分散） | [2026-06-06] |

> 「妖币和之前的算稳 3,3 没什么区别，只是庄家聚合筹码强制 3,3，然后大家去博弈涨跌」[2026-06-02]

## 六、进场决策速查流程（step-by-step）

```
Step 1 → 判断市场结构（0.1）
    ├── 牛市 → 找庄币底部吸筹区
    ├── 过渡期 → 跟妖币操盘
    └── 熊市/派发后期 → 只做空，不做多

Step 2 → Wyckoff 阶段识别（0.2）
    ├── 吸筹阶段（SC→ST→SOS）→ 准备做多
    ├── 派发阶段（BC→SOW→LPSY）→ 准备做空
    └── 不确定 → WAIT

Step 3 → 查否决信号（第二章）
    └── 任一命中 → SKIP

Step 4 → OI 真假辨别（1.2）
    ├── OI↑+价↓+CVD↓ → 快速做空信号
    ├── 但拉升后 OI 不降 → 假 OI，前面的做空信号不可信
    └── 确认 OI 真实 → 继续

Step 5 → 查努力与结果法则（1.1）
    ├── 放量不涨 → 派发 → 做空
    └── 缩量上涨 → 浮筹已清 → 做多

Step 6 → 确认妖币阶段（1.3）
    ├── 前中期（OI+Vol高，Price低）→ ROI 最优，可进场
    ├── 派发期（Price高+OI/Vol减）→ 风险倍增，降仓位
    └── 后期（筹码紧凑）→ 不做空

Step 7 → 对手盘+挤压判断（1.4-1.6）
    ├── 空头蓄水池满 → 跟多（爆空挤压）
    └── 多头 OI 堆积 → 跟空（爆多挤压）

→ ENTER / WAIT / SKIP
```
