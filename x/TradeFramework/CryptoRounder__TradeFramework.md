# CryptoRounder 交易框架

## 一、方向判断

### 1. 宏观周期定调
- **全局 M2 与 BTC 的滞后相关性**：M2 数据前移 90 天后与 BTC 走势高度拟合，用于判断中期方向
- **巴菲特指标**：美股总市值/GDP > 200% = 强烈警告信号
- **200 日 SMA**：BTC 关键长期趋势线，接近时为重要决策点
- **周线 MACD**：死亡交叉 = 震荡概率高，金叉 = 趋势行情

### 2. 关键支撑/阻力确定
- **VPVR POC（成交量加权控制点）**：最密集成交区，核心支撑/阻力
- **布林带下轨**：强支撑；下轨 - ATR ≈ 插针极限
- **前低/前高**：关键突破确认点

### 3. 市场状态分类
- **趋势行情**：周线 MACD 金叉 + M2 上行 → 做多期权（Buy Call）
- **震荡行情**：周线 MACD 死叉 → 卖期权（Sell Put/Call, Iron Condor）
- **恐慌行情**：巴菲特式买入机会，等错杀

## 二、期权策略体系

### 核心策略矩阵

| 市场状态 | 策略 | 操作 |
|----------|------|------|
| 震荡偏多 | Sell Cash-covered Put | 卖看跌期权收权利金，跌破行权价则接货建仓 |
| 震荡偏空 | Sell Covered Call | 已有现货时卖看涨期权，涨破则止盈 |
| 宽幅震荡 | Iron Condor | 同时卖虚值 Put 和 Call，吃双边权利金 |
| 趋势看涨 | Bull Call Spread | 买低行权价 Call + 卖高行权价 Call |
| 重大事件前 | Double-buy Options | 买双边期权博弈波动率放大 |

### 马丁策略（震荡行情加仓）
- 初始仓位 < 0.1 倍
- 优先 sell put，跌破行权价 → 接多单
- 接多后 → sell call
- 未止盈且价格继续跌 → 等额加仓（马丁）
- 以一周内的末日期权为主

## 三、核心指标与工具

| 指标 | 用途 | 参数 |
|------|------|------|
| 布林带 (Bollinger) | 震荡区间识别 | 默认 20,2 |
| ATR | 波动率估算，插针范围计算 | 默认 14 |
| MACD 周线 | 大趋势判定 | 周线 |
| ASR-VC 4h | 震荡行情支撑/阻力（@cryptopainter 指标） | 4h |
| VPVR POC | 密集成交区 | 日线/周线 |
| M2 全球货币供应 | 宏观领先指标 | 季频，前移 90 天 |

## 四、仓位管理

- **初始仓位 < 0.1 倍**：极度保守开仓
- **马丁等额加仓**：不等比例，等金额
- **以 ETH 作为保证金**：卖 BTC 期权，赚 BTC 同时不放弃 ETH
- **sell call 行权 = 止盈**：接受被动止盈

## 五、执行工具

- **OKX 图表分析工具**：免费，布林带+ATR 一键添加
- **GreeksLive**：支持 OKX 期权 RFQ，最小询价 $50,000（权利金只需一小部分）
- **OKX 金融日历**：宏观事件驱动
- **TradingView**：M2 指标、社区脚本

## 六、核心原则

- **"只做观察，不做预测"**（巴菲特式思维）
- **"等错杀机会，以捕食者姿态入场"**
- **"手里有钱才能在别人恐惧时贪婪"**
- **震荡行情要有耐心，趋势行情要敢持仓**
