## 一、Wyckoff三大法则（核心框架）

> 「背后其实用wyckoff三大法则很好解释」[2025-07-20]

### 1.1 Supply & Demand（供需法则）

- 下降区间底部 → 抛售狂潮(SC) → 支撑 → 主力散户高量换手
- 底部盘整区间散户参与度低 → 主力洗掉浮筹
- 「参与度低的价格其实一点都不重要，更重要的是对应的volume，volume背后对应的是interest」
- 突破放量线成功 = 强势信号
- 「在底部共识度和参与度都在主力手里 → 上涨原因。上涨过程中筹码从主力流向散户，共识度下降，但supply > demand保持趋势」

### 1.2 Cause & Effect（因果法则）

- 底部吸筹和换手（Cause）→ 筹码控制权从散户→主力 → Demand/Supply反转（Effect）
- 「底部的吸筹越长，换手和洗掉浮筹的百分比越高 → spring & shaking频繁出现的原因」
- 「因为有底部的吸筹和换手，所以才会有后面上涨的趋势」

### 1.3 Effort & Result（努力与结果）

> 「散户大量的买，但价格上涨的很少 → 很大的effort(volume)，很小的result(price) → 背后的反转信号」

- 抢购高潮(BC) = 大量买盘但价格几乎不涨 → 主力派发信号
- 案例：pengu（圈内机构都用其头像时）→ 筹码出现抢购高潮 → 主力派发
- 案例：泡泡玛特（国内舆论围绕时）→ 短期抢购高潮 → 主力派发

## 二、Wyckoff吸筹-拉升-派发周期

### 2.1 吸筹阶段识别

> 「大环境是牛市的市场背景，找到有庄的，用wyckoff的方法去寻找底部的支撑」[2025-08-21]

**入场信号流程**：
1. **SC（恐慌抛售）**：放量大阴线 → 价格得到支撑 → 长下引线（未知力量消化抛售筹码）
2. **再吸筹**：weak hands和strong hands筹码交换 → 底部连续几天long wick
3. **二次测试（ST）**：价格可能达到前低，但**量非常少** → **最佳入场时机**
4. 止损：前低下面1-2个点
5. 收益率：损失的5-10倍

> 「二次测试缩量，那么就是非常好的入场时机……首先价格在底部，止损前低下面1-2个点，然后收益率是损失的5-10倍可能还不止，最重要的这种盈率非常高」[2025-08-21]

### 2.2 拉升阶段

> 「在拉升的早期是oi增多，价格上涨……这个阶段是最舒服最顺畅也是风险最低的」[2026-04-12]

- 拉升早期：OI↑ + 价格↑，demand > supply
- 庄拉升过程中连环挤压空头 → 拉升一个阶段后进入盘整
- 盘整目的：洗掉早期多头浮盈（OI减少+价格下跌）
- 盘整中短时间跌破 → 给人很弱的感觉 → 吸引做空 → 套住空头

### 2.3 派发阶段识别

> 「主力并不是等到最高点再出货，主力在拉升的过程中就会出货，主力出货看的是流动性」[2026-03-10]

**两种派发模式**：
1. **挤压空头时出货**：空头被挤压 → 买方能量+新资金OI进场 → 巨大流动性 → 主力出货
2. **假突破出货**：在压力位/支撑位 → 给你要往上突破的感觉 → 新资金+空头平仓 → 更高流动性 → 主力在高位多呆 → 做多仓位一平 → OI巨量下跌

> 「主力派发就是给你一个要往上突破的感觉……最后主力做多的仓位一平，oi巨量下跌，主力做多的仓位同时减少，带来的巨量下跌，最后很多人被高高挂起」[2026-03-10]

### 2.4 派发后期→真下跌

> 「派发后期……越在底部波动越小走势越慢机会越少」[2026-04-07]

**derrrrrrrq最擅长的交易**：
> 「我最擅长做爆拉，终极挤压后的那段震荡下跌，胜率真的很高，波动大，流动性也很好」[2026-04-07]

**下跌期间反弹判断**：
> 「真下跌阶段的反弹一定会有一段时间维持在布林带中轨或者之上（这段时间比之前下跌盘整的时间要长）」→ 不是做多信号，而是清理仓位和为后续AR做准备

> 「永远要记住，你要做对的方向，派发后期的AR是套住多头流动性和清理空头，即使你知道反弹也不要去做」[2026-04-07]

## 三、筹码结构决定走势

### 3.1 强控盘（仅合约）vs 带现货派发

> 「$STO拉倒0.26的时候，其实往上0.3完全可以产生连锁挤压效应，庄没挤压，因为庄的空头仓位一直在……带现货派发的筹码结构和alpha强控盘的筹码结构，那是完全不一样的」[2026-04-08]

| 类型 | 特征 | 走势 | 案例 |
|------|------|------|------|
| **强控盘(Alpha/仅合约)** | 现货筹码外部无压力，庄为所欲为 | 只要空头持续进场就可持续挤压 | $SIREN |
| **带现货派发** | 有解锁盘，庄手里有空头仓位 | 拉升受限，难以产生连锁挤压 | $STO |

### 3.2 筹码集中度的极限

> 「siren应该是在98%+以上，所以现货你是买不到筹码的」[2026-04-12]

> 「现货筹码的集中度越高，这个币理论能拉的价格上限越高，对于siren可以无限拉的」[2026-04-12]

- 高控盘=定价权在庄手里 → 做空者永远交资金费率给庄

## 四、对手盘与蓄水池理论

### 4.1 核心原理

> 「流动性和对手盘，永远是操盘者眼里的第一要务」[2026-03-20]

> 「庄家手里浮盈45M的时候，庄为啥不去挤压空头？因为浮盈45M和浮亏45M基本上都是自己的仓位」[2026-05-04]

- 有对手盘才有盈利空间，没有对手盘=自己玩自己
- OI大但交易量小 → 对手盘大概率是庄自己 → 不进

### 4.2 蓄水池理论

> 「清晰知道蓄水池都是操盘手口中的肉……当蓄水池水慢慢褪去的时候，操盘手也好聪明的交易员也好才会漏出撤退的迹象，因为肉少了不够分了」[2026-03-14]

> 「如果你明白这个道理，你基本上不会在蓄水激烈的时候参与进去」[2026-03-28]

- 蓄水池增大 = 燃料增加 = 操盘者可不漏痕迹退出
- 蓄水池枯竭 = 对手盘不够 = 下跌开始

### 4.3 挤压方向判断

> 「为什么不挤压空头？因为挤压空头需要逼空，庄手里一堆空头仓位，而且上方那么多套牢的多头仓位，往下挤压还能让他们爆仓提供流动性」[2026-04-07]

- **向下挤压多头**：庄手里有空头仓位 + 上方套牢多头 = 爆仓提供流动性
- **向上挤压空头**：需要逼空，前提是空头蓄水池足够大

## 五、OI分析进阶

### 5.1 OI≠单一指标

> 「如果你只是仅仅从技术层面分析oi和价格的关系，其实意义并不大……你最好站在操盘者的视角，带入思考」[2026-04-12]

拉升过程中OI变化的4种力量：
- 空头爆仓/平仓 → OI减少 + 买单(demand)
- 多头平仓 → OI减少 + 卖单(supply)
- 多头开仓 → OI增加 + 买单(demand)
- 空头开仓 → OI增加 + 卖单(supply)

### 5.2 OI造假识别

> 「OI在增加，价格下降，CVD下降……一般这种明目张胆堆做空OI的都是庄的行为」[2026-05-22]

> 「图1和2中的oi是庄在造假的，可能过程中部分多空双开」[2026-05-22]

**造假迹象**：
- OI增加 + 价格下跌 + CVD下降 + 拉升回来后空头OI比拉升前低很多 = OI造假
- 案例：$BSB 「应该是近期见到的最妖的没有之一了」

### 5.3 隐藏仓位技巧

> 「在挤压的末尾，主力会在那段时间同时开启双向仓位，多空双开，这样交易量和oi都会放大」[2026-03-28]

> 「后续的盘整过程其实就是把多头平仓，保留空头……平多在盘整区间还能营造弱势」

### 5.4 真假妖币判断

> 「最近的妖币，其实都挺假的，上不了量……合约盘口10wu仓位能把针插飞大几个点」[2026-04-30]

- 真妖币：OI单向10M+但盘口深度极差 → 庄自己双开 → 多空通吃
- 「这种不算真正的妖币……进场砍头息，进去就被宰」
- 「OI+爆仓+Liquidation可以一起看」来确定是真OI还是假OI [2026-05-03]

## 七、真假突破判断

> 「很多人会觉得假突破和真突破很难区分？其实这不是从小趋势去看，从大的趋势去看」[2026-05-19]

| 周期 | 突破性质 | 操作 |
|------|---------|------|
| **吸筹/再吸筹周期** | 真突破（吸筹拉升周期） | 可以做多 |
| **派发/再派发周期** | 假突破拿多头流动性 | 不应做多 |

> 「从wyckoff视角：先去分析处在哪个周期。比如派发周期，拿多头流动性就是常态，起码这里你不应该去做多；比如吸筹拉升周期起码这里你不会去做空」[2026-05-19]
