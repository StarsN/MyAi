# derrrrrrrq 交易框架

> 时间跨度: 2024.04 – 2026.05 | 来源: 507 篇 X 帖子
> 定位: Wyckoff + 订单簿 + 链上跟踪 + AI 工具链

---

## 第一层：市场方向判断
- **Wyckoff 阶段识别**：判断当前处于吸筹(A-D)还是派发(B-C)阶段
  - SC（恐慌抛售）→ AR（自动反弹）→ ST（二次测试）→ SOS（强势信号）
  - PSY（初始供给）→ BC（购买高潮）→ SOW（弱势信号）→ LPSY（最后供给点）
- **市场结构周期**：牛市/熊市/过渡 → 决定策略重心
  - 牛市：找庄币底部吸筹区，做多为主
  - 过渡期：高控筹妖币操盘跟踪，多空灵活
  - 熊市：做空高估值新币（如 RESOLV 上币安后）

## 第二层：主力行为检测
- **筹码分析**：
  - 交易所冷钱包地址充值/提现（如 Bitget 冷钱包 0xffa...）
  - 项目方/做市商地址持仓变化
  - 链上 Smart Money 盈亏追踪
- **OI 结构分析**：
  - 区分：主力构建的 OI vs 散户 follow 的 OI
  - 多头 follow OI 过多 → 洗盘概率高
  - OI 变化 + 价格背离 → 主力意图信号
- **订单簿深度**：limit order 被 market order 消化的速度和量 → 真实供需方向

## 第三层：入场时机
- **吸筹确认**：SC 后价格获得支撑 + 缩量盘整 + OI 结构健康
- **派发信号**：拉升过程中主力出货（看流动性而非价格）+ OI 异常增长
- **挤压识别**：
  - 多头挤压：空头蓄水池满 → 主力拉盘爆空 → 跟随做多
  - 空头挤压：多头 OI 堆积 → 主力砸盘爆多 → 跟随做空
- **杀猪盘识别**：合约盘口极浅（10wu 仓位插飞几个点）+ OI 双向都大 → 多空双杀 → 不参与

## 第四层：仓位与风险管理
- **不做比做什么更重要**：过滤掉 90% 的机会
- **确定性高才上仓位**：认知 → 定价偏差 → 仓位大小
- **止损**：基于主力 OI 均价或 Wyckoff 关键支撑/阻力位
- **盈亏比**：追求高赔率，每笔交易预设预期外 case 的应对方案

## 第五层：执行与工具
- **AI 工具链**：8 个自建服务（主力跟踪、OI 监控、链上异动、盘口分析、操盘归类）
- **数据平台**：自建底层数据架构，日均百万级数据流入流出
- **持续迭代**：将操盘特征输入到系统中 → 肌肉记忆化 → 更快识别
- **复盘**：每笔交易后记录，反思认知偏差和模型漏洞
