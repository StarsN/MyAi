## 一、交易的本质：预期管理

### 核心命题

> 「无法看清本质，很难做好预期判断。」[TH]

市场永远交易的是**预期**，而非**事实**。当事实兑现时，价格往往已提前反应。

### 预期的四层结构

| 层次 | 问题 | 例子 |
|------|------|------|
| 市场在交易什么 | 当前定价的是什么预期？ | 降息预期 |
| 谁在制造这个预期 | 谁是信息源？ | 美联储官员讲话 |
| 制造预期的目的是什么 | 动机是什么？ | 管理市场情绪，为政策铺路 |
| 预期能否兑现 | 预期差有多大？ | 劳工部和美联储利益出发点不同 |

### 预期差交易

> 「我的预判是低于上个月，至于是否符合预期……按照美联储对非农的强管理，可能不会偏离太多。」[TH]

交易员的竞争力在于：
1. 提前识别市场在交易什么预期
2. 判断预期是否已被充分定价
3. 找到预期差（市场定价 vs 实际结果）

## 二、宏观决定论：一切资产都是政策工具

### 三层博弈模型

```
第一层：市场参与者（散户/机构）在交易数据
第二层：大型机构在交易政策
第三层：政策制定者在利用市场实现战略目标
→ 交易员必须站在第三层思考
```

> 「一切经济政策的目的总是为了政策服务。」[TH]

- 美联储降息不是为救市，是为特定目的（吸血盟友/转嫁风险）
- 关税不是为制造业回流，是为制衡和谈判筹码
- 访华/外交不只是外交，是配合金融市场操作的手段

### 资产串联因果链

> 「原油价格 → CPI/PPI 调涨 → 加息预期衍生 → 美债 5% 收益率 → 沃什交易 → 访华前动作暗示 → 日元油价联动 → EMA200 → 单边下跌」[2026-05-18]

> 「上述是连环相套非独立，因此上述均破，会带来单边。」[2026-05-18]

核心原则：各环节方向一致、无断裂→单边行情。任一环节矛盾→等待。

### 沃什交易 (Warsh Trade) 理论 [2026 新增]

> 「沃什交易的根本是对冲交易」[2026-02-09]

```
沃什（鹰派倾向美联储主席候选人）
    ↓
降息+缩表 = 对冲性政策 → 引发市场分歧
    ↓
防止市场抢跑 → 防止单一层面的资本外流
    ↓
目的：让美元有序贬值
```

> 「沃什的价值是强化市场分歧——需要降息就降息，需要缩表就缩表」[2026-02-09]

> 「有鹰派倾向的沃什而言，跌给他更像'你tm缩表试试，给你个下马威'，叠加新旧两派的暗自较量」[2026-05-18]

## 三、市场操纵论：庄家决定一切（v2 升级版）

### 核心信念不变

> 「可能是庄怕我真的离开了吧，入圈以来第一次庄和政策面按我思考的方向在走。」[TH]

价格涨跌取决于庄的行为，不是散户情绪。交易的核心是识别庄的动机和成本。

### 庄行为四阶段

| 阶段 | 特征 | 验证信号 |
|------|------|---------|
| 建仓期 | OI 缓慢积累，价格横盘或微涨 | OI↑+ 价平 |
| 拉升/砸盘 | 利用消息面或技术面触发止损/爆仓 | 成交量放大+OI 持续高 |
| 出货期 | 回购公告/利好消息配合，左手倒右手 | 项目方回购=拉盘计划取消 |
| 撤退 | 平稳出货，流动性管理 | OI 萎缩+价横 |

### 庄控盘程度判断体系 [2026 新增]

| 维度 | 高控信号 | 出处 |
|------|---------|------|
| OI/市值比 | 盘前合约持仓 = 市值 50%+ → 庄建仓 | [TF] |
| 筹码集中度 | 前 10 地址控筹 95%+ | [2025-10-09] |
| 池子深度 vs OI | 池子深度能覆盖数倍 OI → 庄能控制价格 | [TH] |
| 基差变化速率 | 基差几乎不变 → 极高控盘（90%+） | [2026-05-07] |
| 订单簿护盘 | 关键价位有 50w+ 买单加厚度 | [2026-05-07] |
| 下跌中收现货 | Gate 等所有大量现货买单 → 庄在收筹 | [2026-05-07] |

### 项目方回购陷阱

> 「项目方回购 = 左手倒右手可以不花成本 → 取消短期拉盘计划 → 平仓。」[TH]

## 四、基差与溢价分析理论 [2026 核心新增]

### 基差-费率-方向联动

BTC_Alert 在 2026 年将币安的基差和溢价指数作为核心判断工具：

```
合约价格 vs 指数价格偏离 → 进入费率计算（每 5 秒一次）→ 加权平均
    ↓
现货 > 合约 + 标记价 < 指数价 + 费率非正
    ↓
模糊判定：多单在平仓
```

> 「经常操盘的朋友不要忽视：除了基差收敛，币安溢价造成的费率影响也挺麻烦」[2026-06-01]

### 盘前合约的定价陷阱

- 盘前合约 **无指数价格**（无现货指数）
- 标记价格和清算价格与最后成交价相关
- 多的人多就涨，空头被清算，多头被 ADL
- **结论**：盘前合约 = 纯 meme，不能用正常基差逻辑判断 [2026-06-01]

### 韩所基差交易逻辑

> 「在当前少散户参与山寨的情况下，基差变化更容易捕捉拉盘前夕」[2026-03-30]

## 五、IP 估值理论（Meme 币体系）

### 核心框架

将名人币/Meme 币视为 IP 资产：

1. **IP 影响力** = CZ/特朗普等人物在币圈甚至金融圈出圈的影响力形成的最大公约数
2. **估值方法** = 类比估值法（参考 doge/pepe 的 IP 变现模式）
3. **共识分散** = 第二个同类 IP 只有第一个的 20% 市值

### IP 生命周期

```
IP 诞生 → 共识形成 → 价值发现 → 共识分散 → 价值稀释
                                  ↓
                        有机会：二次收集筹码 → 第二波拉升
```

### CZ 狗案例

> 「CZ 狗出来 → 平掉 TST 多单」[TF]

## 六、流动性为核心的分析体系

### 三要素

| 要素 | 问题 |
|------|------|
| 池子深度 | 多少钱能推动价格？会不会自己踩自己？ |
| OI 变化 | 资金在进还是出？庄在布局还是撤退？ |
| 基差/费率 | 多空平衡状态？有套利空间吗？有介入痕迹吗？ |

### 做多/做空/不出手条件

| 条件 | 判断 |
|------|------|
| 做多 | 流动性充沛，对手盘可被消灭 |
| 做空 | 流动性枯竭，市场无法承接抛压 |
| 不出手 | 流动性太薄，自己踩自己 |

> 「现在都啥样了，新币现货的交易量没以前的三分之一，合约日交易量过千万的就少。MM 订单簿稀薄得很，这让交易员仓位和操作空间变得很少」[2026-03-12]

## 七、空踩空回油理论 [2026 新增]

BTC_Alert 在分析妖币暴跌后的反弹时，提出了「空踩空回油」机制：

```
空单密集 → 价格下跌 → ADL（自动减仓）强制平空 →
空单获利平仓 → 双重回补买盘 → 价格反弹
```

> 「现货砸盘没人接，合约没逻辑 OI。如果要空单获利，则空踩空回油反弹」[2026-05-26]

## 八、风险与不确定性管理

### 不确定性四级分级 [v2 升级]

| 级别 | 条件 | 操作 |
|------|------|------|
| 逻辑清晰 | 宏观+对手盘+流动性方向一致 | 满仓/杠杆 |
| 有干扰 | 逻辑成立但单一因素扰动 | 主仓位不动 |
| 结构风险 | 关键结构位临破或宏观转向信号 | 卸杠杆、戴套 |
| 完全不确定 | 多因素矛盾，方向不明 | 持 U 等待击球点 |

### 核心原则

1. **「不要卖出现货」** — 长期信仰不可动摇
2. **「走掉多单」** — 短期方向不确定时卸掉杠杆
3. **「戴套」** — 永远保护敞口（期权双压、现货网格、盘前对冲）
4. **「现金为王」** — 脆弱时期持 U 等待
5. **「等待好的击球点」** — 不做频繁交易

## 九、交易员成长理论

> 「很多人无法形成自己的交易体系在于没有路径确认交易目的、风险辨析、风险偏好、决策执行。」[TH]

### 四大障碍
1. 判断依据来源单一
2. 头寸无对冲
3. 交易方式单一（只买涨卖跌，不会吃波动和期权）
4. 未能辨析交易对手盘

### 复盘的意义

> 「复盘的意义就是对自己交易预期、交易依据的认证与修正，并不是找个理由证明自己多对。」[TH]

### 社区与交易体系

> 「大多数人不是没有能力做到这一点，是不去训练自己这样的思维，不去验证信息，不去根据风险偏好执行交易。只想后入，只问别人在不在，这种就很难提高」[2026-06-05]
