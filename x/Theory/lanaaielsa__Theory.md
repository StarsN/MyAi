## 一、信息不对称 Alpha 理论
币圈是一个极度信息不对称的市场。超额收益的关键不在于技术分析能力，而在于：
- 更早地发现信息（链上数据、社交舆情、叙事变更）
- 更准确地解读信息（理解币安战略意图、MM 行为动机）
- 更快地行动（AI 工具辅助执行）
核心信念：定价偏差 = Alpha，与市场共识的偏差越大，潜在收益越高。

## 二、飞轮驱动价值理论
NFT Strategy 生态验证了一种纯合约驱动的价值飞轮：
- 国库买入 → 资产升值 → 市值增长 → 更多买入 → 国库增长
- 关键条件：合约能自动永续执行（Punk 策略的独特性）
- 差异：721 策略需人工触发 → 飞轮间歇性 → 效率低于 Punk
核心信念：最好的投资标的是那些"只要有人交易就能自动增长"的系统。

## 三、MM 做市商之春理论
2026 年初提出的一级市场新范式：
- 做市商寻求买币安合约壳（供给端需求）
- MM 选择"鱼多"的标的做市（广场流量 = 鱼塘）
- 关注币安广场的高流量币种 → 等同于链上抓资金流动
核心信念：做市商的行为是可预测的，他们的入场信号隐藏在广场数据和合约壳交易中。

## 四、币安上币流水线理论
币安通过 Alpha → Aster → Perp → Spot 四级路径系统化地捕获链上价值：
- 优势：压缩二线所空间，巩固币安独一档地位
- 代价："能否上币安"成为估值的唯一锚点 → 市场定价权过度集中
- 机会：在 Alpha 或 Aster 阶段提前布局，在 Spot 阶段（共识最一致时）退出
核心信念：理解交易所的战略意图 = 理解市场的流动性流向。

## 五、预测市场关联套利理论
Polymarket 不是赌场，是信息市场：
- 关联事件存在概率传导（事件 A → 事件 B）
- AI 可以辅助处理大量跨领域信息 → 发现定价偏差
- 非方向性押注，而是寻找"市场的定价错误"
核心信念：预测市场的 Alpha 来自信息处理能力差异，而非运气。

## 六、策略进化论
交易能力的提升是一个不断寻找新 Alpha 来源的过程：
- 港美股壳股 → 链上 PVP → NFT 策略 → 预测市场 → Hyperliquid → AI 工具化
- 每进入一个新领域，初期享受低竞争红利
- 随着竞争者涌入，转移到下一个低竞争领域
- AI 工具可以加速这个迁移过程
核心信念：不执着于单一策略，永远寻找下一个信息不对称洼地。

## 七、筹码接力理论
一个标的能做大，核心是筹码结构 + 接力资金：
- 底部控盘 → OTC 给 KOL → 突破 FOMO → 多波接力
- 单一大户拉盘不可持续，多波资金接力才健康
- 类比电影《金手指》：每一个价位都有人接力推动
核心信念：看一个标的能否起飞，先看筹码有没有人接力。
