## 一、市场驱动力信念

### 叙事是市场的第一驱动力
- **「叙事轮动」理论**：市场不是随机波动，而是叙事驱动
- 每周期有主导叙事：2023 — L1/矿币 | 2024 — AI/DePIN/RWA | 2025 — Meme/稳定币/BSC
- 「VC 币的破局也很简单，有社区有共识有强庄」

### 叙事生命周期
事件 → 叙事发酵 → 资金流入 → 价格上涨 → 叙事扩散 → 更多资金 → 见顶

### 注意力第一原则
> 「无论是牛市还是熊市，注意力是第一位的」[2026-05-14]

> 「alpha 上的项目基本面研究失效了，就是要盯着项目方的地址是不是出货」[2026-05-28]

## 二、市场参与者层级：权力结构决定利润流向

| 层级 | 角色 | 能力 |
|------|------|------|
| 最高层 | 交易所 + 做市商（MM） | 控制盘面、决定上币、分配流动性 |
| 中间层 | VC/投资机构 + 项目方 | 控筹、融资、叙事制造 |
| 操作层 | KOL + 社区领袖 | 信息传播、情绪引导 |
| 底层 | 散户 | 提供流动性和对手盘 |

> 「合约市场本质是 MM 与散户的对赌。庄家控制盘面，散户要做的就是识别庄的意图并跟随」[TH]

> 「我们靠什么赚钱，要清楚自己的位置：我们都是普通人」[TH]

## 三、MM（做市商）行为理论

### 两种 MM 类型

| 类型 | 行为模式 | 散户策略 |
|------|---------|---------|
| **主动 MM** | 拉砸 K 线、爆仓获利、控盘操盘 | 跟车 |
| **被动 MM** | 仅帮项目方卖货、提供基础流动性 | 回避 |

> 「区分主动 MM vs 被动 MM：主动 MM 拉砸 K 线爆仓获利→跟车；被动 MM 仅帮卖货→回避」[TF]

### MM 的两种获利路径

**路径一（高控合约项目）**：
```
项目高控 → 不上现货（现货要交筹码）→ 利用 MM 配资 →
拉盘爆空 → 拉高派发出货
```

**路径二（上现货项目）**：
```
合约上线 → 阴跌吸筹（项目方低价接筹码）→ 上现货 →
庄出货 + 合约开空单 → 等韩所拉一波继续出货
```

> 「上了合约后大部分的项目不考虑上现货，有 MM 做市商的话就猛拉盘，拉高出货和拉高爆空的方式赚钱」[2026-05-14]

### 洗盘演变论

> 「现在项目洗盘的方式越来越极端了」[2026-04-30]

```
旧模式：横盘消磨 → 洗掉不坚定持有者
新模式：一直拉盘 → 直接砸盘 → 洗掉多单 →
        再拉盘吸引空军 → 爆空
```

### 庄意图验证框架

> 「庄的操盘手法，最简单直接的一个方式，盯一个币 3 周，找规律，找庄的操盘手法」[2026-05-25]

| 验证问题 | 方法 |
|----------|------|
| 庄有没有在链上出货？ | 盯项目方地址的链上行为 |
| 拉盘的目的是什么？ | 爆空 / 冲合约 / 吸引注意力 / 拉高出货 |
| 庄的多单/空单平均成本在哪？ | 决定入场安全边际 |

## 四、合约市场结构理论

### 合约类型决定做盘逻辑

| 合约身份 | 控盘程度 | 做盘逻辑 | 操作策略 |
|----------|---------|---------|---------|
| alpha+合约（仅合约） | 高控（前10地址>90%） | 拉盘爆空→派发出货 | 顺着 MM 意图做多 |
| alpha+合约→现货预期 | 中高控 | 低价接筹码→上现货→出货 | 等待阴跌底部+博现货 |
| 已上现货 | 控筹分散 | 非妖币逻辑 | 波段为主 |

### 妖币形成信号

```
OI 持仓 > MC 市值 → 妖币潜力
全网合约成交量持续放大 → 确认趋势
出现巨鲸爆仓（百万级 USD）→ 妖币属性确认
```

> 「还没形成妖币的结构」= OI 相对 MC 还不够大 + 爆仓金额不高 [2026-06-07]

### 底部埋伏的三方博弈

> 「一堆人都以为是底了，一堆人一起建仓 → 庄大概率会砸盘洗掉这些人再考虑拉盘」[2026-05-22]

社区（散户）、自己、庄家的三方关系中，当底部筹码过多（跟庄抢筹），庄会选择重新暴力洗盘而非拉盘。

## 五、估值与定价理论

### 代币估值方法论

| 项目类型 | 估值依据 | 何时拉盘 |
|----------|---------|---------|
| L1/DeFi/DePIN | 基本面（团队/融资/产品/TVL） | 赛道轮动或上所 |
| 高控合约币 | MC 接近合约壳子价格+历史多次爆拉 | 洗盘结束、OI 积累后 |
| Meme/IP 币 | IP 热度和社区共识、链上 OG 盘 | 叙事爆发期 |
| 上币预期币 | 团队+VC 背景+与币安关系 | 上币公告前后 |

### 低开 vs 高开的拉盘动力学

> 「alpha 上的项目最近最大的问题是给太高的开盘市值了，导致项目方完全没有拉盘的动力」[2026-05-26]

- **低市值开盘 + 高控 + 冲合约预期** → 项目方有动力拉盘
- **高 FDV 开盘** → 项目方没动力拉盘，「币是空气，卖出的 U 才是真金白银」

### IP 估值理论（Meme 代币）

- Meme 币的价值来源于 IP 的文化共识
- 关键指标：IP 热度、社区共识强度、链上 OG 盘识别
- 流动性溢价：大所上币带来流动性溢价（币安现货 > 合约 > Alpha）

## 六、交易方法论分化

Arya 的框架中隐含着三种完全不同的交易模式：

| 模式 | 标的类型 | 核心逻辑 | 持仓方式 |
|------|---------|---------|---------|
| **波段** | 有 MM 的 VC 版 Meme | 大涨卖、大跌买、不追高 | 现货 |
| **妖币** | OI>MC 的高控合约币 | 识别洗盘→跟庄→爆空获利 | 合约（5x） |
| **埋伏** | 低市值 alpha 币 | 买在无人问津时→等拉盘 | 现货，死拿 |

## 七、风险哲学

### 对杠杆的态度演变
- 2023-2024：**坚决不做合约**，「不做杠杆与合约」
- 2025-2026：开始用 5 倍杠杆，但**必须设止损**；妖币时「合约根本拿不住，只能死拿现货」

### 复利滚仓理论（小资金 1000U）

> 「选择一个 alpha 标的买进去等翻倍→1000U变2000U→再找下一个翻倍标的→依次滚下去」[2026-05-06]

### 2:8 定律
- 「赚钱的永远是少数」
- 「财富永远在时时刻刻转移」
- 站在趋势的一边，站在庄的一边

### 认知诚实
- 「我到现在都没有建立完整的投研体系」— 承认认知局限
- 「最好的方式就是建立终身学习体系」
