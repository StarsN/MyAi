## 一、Wyckoff 市场操纵理论

### 核心信念

市场不是随机的，由主力（Composite Operator）操控。通过量价+OI+链上数据可以提前识别主力的吸筹/派发意图。

### 三大法则

| 法则 | 内容 | 实战信号 |
|------|------|---------|
| **供给需求法则** | 价格由供需决定，量价关系揭示真实供需 | 订单簿 imbalance 判断方向 |
| **因果法则** | 吸筹区间大小→后续涨幅大小 | SC-ST-SOS 区间确认后量目标位 |
| **努力与结果法则** | 放量不涨→派发；缩量上涨→浮筹已清 | 最核心的即时信号 |

### 吸筹阶段序列

```
SC（恐慌抛售）→ AR（自动反弹）→ ST（二次测试）→ SOS（强势信号）
```

### 派发阶段序列

```
PSY（初始供给）→ BC（购买高潮）→ SOW（弱势信号）→ LPSY（最后供给点）
```

### 短期 AR 的形成机制 [2026 新增]

> 「庄的空头仓位要平仓，就会有反弹，配合新的做多进场，自然而然有反弹——背后就是短期 AR 的形成」[2026-05-28]

## 二、妖币理论：强制 3,3 + 筹码紧凑化

### 妖币本质

> 「妖币和之前的算稳 3,3 没什么区别，只是庄家聚合筹码强制 3,3，然后大家去博弈价格的涨跌」[2026-06-02]

```
传统算稳 (ESD/OHM):  智能合约控制的 3,3 → 受代码约束
妖币:                 庄家聚合筹码强制 3,3 → 主动 MM 掌控，玩法更多元
```

> 「妖币借助多 CEX 市场的流量，触达的用户和拉新的用户和之前不是一个维度。妖币反而会持续不断的发展进行」[2026-06-02]

### 妖币筹码演变规律 [2026 新增]

| 阶段 | 筹码特征 | 含义 |
|------|---------|------|
| 前中期 | 筹码在主力手中聚集 | OI+Vol 最重要，price 不重要 |
| 中后期 | 筹码越来越紧凑 | 流通盘越来越小，庄控盘越来越强 |
| 末期 | 极度紧凑 | 做空 ROI 极低，对手盘难培养 |

> 「共识币价值币是越往后筹码越散，妖币是越往后筹码越紧凑」[2026-06-06]

### 妖币前中后期指标重心转移

```
前中期: OI + Vol（交易兴趣+换手）→ 不看 Price/MCap
派发期: Price + MCap（估值+风险）→ OI/Vol 在减少
```

### 妖币做空的核心矛盾

> 「做空妖币要看的是背后的 ROI——能有多少收益，会有多大损失。妖币越往后筹码越紧凑，做空 ROI 越来越低」[2026-06-06]

做空启动前的妖币 vs 做空已在运行的妖币 → 资金层面和筹码层面天差地别 [2026-06-06]

## 三、OI 结构理论：真伪之辨 [2026 核心新增]

### 主力 OI vs 散户 OI

| 类型 | 特征 | 策略含义 |
|------|------|---------|
| 主力构建的 OI | 大额 + 集中 + 与价格联动合理 | 真实方向信号 |
| 散户 follow OI | 小额 + 分散 + 滞后于价格 | 洗盘的燃料 |
| **造假 OI** | 多空双开 + 价格方向与 OI 方向矛盾 | 烟雾弹，不可信 |

### OI 造假手法识别

> 「OI 在增加 + 价格下降 + CVD 下降 → 一般这种明目张胆堆做空 OI 的都是庄的行为。拉升回来后 OI 基本没降低多少 → 下跌过程中有不少烟雾弹 OI。拉升回来后空头 OI 比拉升前低很多 → 之前的空头 OI 是假的」[2026-05-22]

```
识别方法:
1. 看 OI↑+价↓+CVD↓ → 表面空头堆积
2. 等拉升 → 看 OI 是否降低
3. 拉升后空头 OI 大幅低于拉升前 → 假 OI（庄多空双开）
4. 拉升后 OI 几乎持平 → 真实空头还在（可信）
```

### 多市场 OI 构建

> 「从 aster esports OI 去看，就能推断 aster 的自营做市是存在的」[2026-05-26]

跨交易所的 OI 联动 → 可以推断做市商的存在和仓位分布。

## 四、对手盘挤压理论

### 主力的盈利模式

```
积累对手盘（诱多/诱空）→ 等待蓄水池满 → 反向挤压 →
对手止损/强平 → 流动性转移给主力
```

散户的盈利模式：**识别主力意图，在挤压前跟随主力方向。**

### 对手盘观测方法 [2026 新增]

> 「币安广场是一个比较好的对手盘观测基地。特征：换手高、涨幅大、OI 低、流动性差」[2026-05-31]

- 低市值妖币：前期积累一些对手盘，挤压一下就拉上去
- 高市值已启动妖币：筹码紧凑，对手盘难以培养

## 五、订单簿微观结构理论

### 核心洞察

- 拉升时 market buy 吃掉 limit sell → 真实需求在消耗供给
- 下跌时 market sell 吃掉 limit buy → 真实供给在压倒需求
- **订单簿深度变化速度 > 深度绝对值**

### 高控盘合约的流动性博弈 [2026 新增]

> 「现货侧的巨大滑点背后就是高控盘合约流动性的博弈。庄要做的就是激活市场、激活流动性，然后大家下注，继续压大小」[2026-06-03]

### 链上噪音识别 [2026 新增]

> 「一个地址一直卖，一个地址一直买——本质上就是来回对敲」[2026-05-24]

链上数据需要区分真实供需 vs 对敲制造的量价假象。
