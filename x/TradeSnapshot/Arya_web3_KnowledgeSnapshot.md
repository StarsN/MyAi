## 1. 核心交易情境

### 偏好环境
- **庄币（MM 控盘代币）**——核心主战场。专注识别做市商意图，跟踪 OI、多空比、费率变化，在 MM 启动爆空/爆多循环中介入。「你要跟庄的动作产生共鸣，你才能玩好庄币。复杂的不是指标，是你身处其中的心理状态。」
- **币安 Alpha 上新**——胜率自评 95%+ 的第二战场。低 FDV 开盘 + 低流通 + 高锁仓结构优先。路径依赖风险：习惯低开→不敢追高开标的（$OPG 教训）。
- **山寨叙事窗口期**——RWA、AI+Web3、DePIN、meme 四大赛道。叙事萌芽期埋伏龙头，人声鼎沸时退出。
- **宏观事件驱动**——CPI/FOMC/ETF 审批作为仓位调节因子。BTC 锚定但不盲从：大盘悲观时逆向建仓好标的（「好的标的真的不等人」）。

### 回避环境
- **低流动性时段**（周末/亚洲凌晨）——庄币不过夜，不盯盘就空仓。
- **纯 VC 币无 MM 护盘**——「无论你怎么复盘，永远不知道庄的下一步要做什么，这就是 VC 币难玩的地方。」
- **高 FDV 开盘 + 无锁仓结构**——大概率派发而非吸筹。

### 时间演变
| 阶段 | 时间 | 特征 |
|------|------|------|
| 投研启蒙 | 2022–2023 | VC 币深度研究，赛道分析为主（RNDR/ONDO/ZEPH），强调基本面 |
| MM 觉醒 | 2024 | 开始关注做市商行为，识别庄币模式，提出「龙头思维+强庄+卡位」框架 |
| 庄币专精 | 2025 | $Rave/$Tradoor/$Siren 等深度参与，形成完整 OI 分析体系 |
| Alpha 精炼 | 2026 | 聚焦币安 Alpha 上新 + 庄币短平快，胜率追求极致，「熊市注意力是第一位的」 |

### 极度看重（核心层）

| 指标 | 提及次数 | 权重逻辑 |
|------|:---:|------|
| **OI 持仓量** | 331 | **#1 指标**。OI↑+价格↑=真趋势；OI↑+价格↓=洗盘/诱空；OI↓+价格↑=庄撤退/派发。OI 是多空双方「押注」的实时地图——庄的头寸在哪边，OI 结构会暴露。关注多周期：15m 短期洗盘、1h 动能、4h 趋势、48h 结构 |
| **做市商行为 / 庄** | 338 | MM 的对手盘和跟车玩家都是目标。「每一次拉升一定是为了爆空单，庄的目的就是爆空单。洗完跟车的多单车轻了，一堆人又去做空了。」 |
| **市值 / FDV** | 691 | 估值锚定核心。FDV 50M 以下 ≈ 安全边际；2 亿+ FDV 开盘 = 贵。但对龙头不设硬上限——「确定是龙头的币，无所谓贵不贵，买就是了」 |
| **多空比 / LSR** | 12 | 极端值反向操作：多空比 < 0.3 → 极度偏空 → 做多窗口；> 3 → 极度偏多 → 做空窗口。但仅在与 OI + 费率共振时有效。 |

### 高度依赖（辅助层）

| 指标 | 权重逻辑 |
|------|------|
| **资金费率** | 极端负费率（-1% 以上）是 MM 启动爆空的前置信号；费率从正转负 = 变盘预警。但在 MM 操盘场景下，费率是「果」不是「因」——费率负是因为空单多，空单多是 MM 诱导的 |
| **筹码分布 / 集中度** | 链上前 10 地址持币 75%+ 是高控盘标志。低流通 + 高锁仓 = 二级抛压极小，这是庄币启动的前置条件 |
| **盘口深度 / 价差** | 用于评估滑点和 MM 在场证据。深度极薄时放弃——不是信号问题，是结构性脆弱 |
| **爆仓数据** | 实时跟踪爆仓金额和分布。大额空单爆仓后 MM 通常撤多单 → 价格回落 → 新一轮诱空循环 |
| **叙事 / 赛道** | 先判断赛道叙事空间，再选龙头。不买叙事已过顶峰的标的。赛道轮动信号 = 提前布局窗口 |

### 基本忽视

- **Taker 买卖比**（提及仅 1 次）——不纳入决策体系
- **纯技术指标（MA/MACD/RSI/布林带）**——「分析起来头头是道不如上点仓位」，仅作辅助参考
- **社交热度 / 社区情绪**——关注但不作为入场依据。「人声鼎沸」是离场信号而非入场信号

## 3. 交易触发与执行倾向

### 右侧切入（主力模式）
1. **OI-多空比-费率三重共振**：OI 增长 + 多空比极端偏空（< 0.5）+ 负费率扩大 → MM 即将拉升爆空。在 OI 确认积累后分批建仓。
2. **龙头确认追入**：「龙头就是龙头，之所以成为龙头就是因为共识强+强庄+叙事卡位」。龙头启动后第一时间建底仓，不停等回调——「研究明白看好的项目，先上底仓，不要因为一直等回调错失暴涨的机会。」
3. **Alpha 上新低开买入**：FDV < 50M + 低流通 + 有币安合约预期的标的，开盘即建仓。不纠结精确买点。

### 左侧接飞刀（辅助模式）
1. **庄成本附近建仓**：币价跌至庄吸筹区间（通常为前期低点或大幅回调 50%+ 后企稳位置），且 OI 未崩塌、链上无大规模出货。
2. **跌无可跌时抄底**：FDV 跌至项目基本面价值以下 + 项目方未弃盘 + 做市商仍在。「买入装死，等待庄或者野庄搞事情。」
3. **利空出尽逆向建仓**：监管调查、负面 FUD 时逢低定投龙头（如 $HYPE 被调查时：「资本主义的调查就是给你低价建仓的机会」）。

### 真突破 vs 假洗盘判别
- **真突破**：OI 持续增长 + 费率未极端 + 价格突破伴随增量资金。确认信号：突破后横盘不跌，OI 维持或继续增长。
- **假洗盘**：价格急跌但 OI 坚挺或增长 → 主力没走，洗盘噪音。价格跌 + OI 跌 → 真派发。**关键区分**：「价格跌但 OI 坚挺 = 主力还在；OI 与价格双杀 = 多头踩踏。」
- **假突破**：价格短暂突破后快速回落 + OI 增长但价格不跟 → 流动性吸收/诱多。

### 庄币完整操作闭环
```
MM拉盘→上涨幅榜吸引注意力→横盘积累空单（空军误以为拉不动）
→费率变负→爆空拉升（大量空单止损触发）
→大额空单爆仓后MM撤多单→暴跌→诱新一轮空单→循环
```
介入点：横盘积累空单阶段（OI 增长 + 价格不涨 + 空单占比上升）
退出点：大额空单爆仓后（MM 目标达成，大概率撤多）

## 4. 风控与退出策略

### 止损防线
- **硬止损**：5 倍杠杆上限，每笔必设止损。「5 倍杠杆+设止损，永不全仓。」
- **结构止损**：OI 15m 出现剧烈崩塌（-3%+）同时价格破关键支撑 → 无条件斩仓，不扛单。
- **时间止损**：庄币持仓不过夜。不盯盘 = 空仓，不设止盈止损 = 不做。

### 无条件退出触发（Tier 升级信号）

| 触发条件 | 动作 | 逻辑 |
|------|------|------|
| **做市商离场**（OI 暴跌 + 链上出货地址活跃） | 立即清仓 | MM 是庄币唯一的价值支撑，MM 走 = 归零风险 |
| **费率极端飙升**（1h 负费率 -1%+ 或正费率 +0.5%+） | 减仓或清仓 | 拥挤交易即将反转，费率极端是变盘前兆 |
| **OI 崩塌**（多周期同步暴跌，15m OI -5%+） | 无条件斩仓 | 资金大面积撤离，结构性崩溃 |
| **关键支撑破位**（跌破庄吸筹成本区） | 止损离场 | 庄放弃护盘，下行空间打开 |
| **情绪高潮退潮**（人声鼎沸 + 媒体刷屏 + OI 不再增长） | 分批清仓 | 「买在无人问津时，卖在人声鼎沸时」 |

### 止盈策略
- **分批止盈**：15%-30% 第一目标减仓 1/3，50%+ 减仓 1/3，留底仓博加速段
- **不追求完美卖点**：「不要想着从头吃到尾，这基本是不可能的」
- **见好就收**：「一旦贪婪你就是鱼。庄币本身就是赌场，落袋为安最重要」

### 仓位管理铁律
- **永不全仓**——永远保留子弹应对极端行情
- **分批建仓 / DCA**——确认逻辑后先底仓，验证后加仓
- **单一庄币不超总仓位 20%**——庄币高波动，单一标的风险不可集中
- **杠杠 ≤ 5x**——这是多次强调的硬上限
