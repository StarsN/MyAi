## 1. 核心交易情境

### 偏好环境
- **妖币（高控筹山寨）**——核心战场。「如果没有控盘的庄币，我感觉我现在啥都不会玩。」专注币安 Perp 上高控筹小市值代币的对手盘挤压交易。
  - 代表标的：PIPPIN、SIREN、RIVER、RAVE、RESOLV、LAB、TRADOOR、STO
- **Wyckoff 大周期结构分析**——底层框架。区分吸筹/派发阶段，识别主力对散户内心的操控。「Wyckoff 核心的用途是主力对于散户内心的操纵，一根根 K 线上/下引线背后其实是 FOMO 和 Fear 的完美写照。」
- **订单簿微观结构（Tape Reading）**——实时战术工具。继承 Wyckoff 和利弗莫尔的 Tape Reading 传统。「价格拉升不代表买的多——是 limit order 被 market order 不停地吃掉。market order = demand，limit order = supply。」
- **多时间框架（MTF）**：日线/4H 看大结构 → 1H/15m 看吸筹 → 5m/1m 抓精确点位。Spring 后的 Higher High（HH）是最稳定的入场点。
- **AI 工具链增强**——自建 8 个 AI 服务，日均百万级数据流入流出。涵盖主力跟踪、OI 监控、链上异动、盘口分析、操盘风格归类。「AI 本身不能产生策略，AI 只是提高你的生产效率。」

### 回避环境
- **杀猪盘（多空双杀盘口）**——合约盘口极浅（10wU 仓位插飞几个点）+ OI 双向都大 = 多空双杀结构。如 TRADOOR：1 小时内上下 165% 振幅，「任何高于 5wU 的仓位都会被庄狙击秒杀。」→ 直接跳过，不参与。
- **拥挤交易**——多头 follow OI 过多 / 散户做空过多 → 洗盘概率高 / V 反概率高。「LAB 太多多头 follow，没办法短时间拉到 RAVE 的高度。」
- **派发周期**——「派发周期拿多头流动性就是常态，起码这里你不应该去做多。」
- **无庄项目**——没有做市商的优质标的也是死水。「QUIL 1B 叙事空间弄到 10M，核心就是没有庄，盘面一点活性都没有。」

### 市场结构周期框架

| 阶段 | Wyckoff 信号 | 策略 |
|------|------|------|
| **吸筹** | SC（恐慌抛售）→ AR（自动反弹）→ ST（二次测试成功） | 识别主力建仓，跟随做多 |
| **吸筹拉升** | SOS（强势信号）+ 缩量盘整 + OI 结构健康 | 重仓做多，趋势持有 |
| **派发** | PSY（初始供给）→ BC（购买高潮）→ SOW（弱势信号） | 不做多，准备做空 |
| **派发下跌** | LPSY（最后供给点）+ 假突破拿多头流动性 | 做空或空仓等待 |
| **结构转变** | 2025.10 前：熊市→做空躺赚。2025.10 后：主力资金重新聚集→做空必亏 | 及时切换策略方向 |

## 2. 微观指标权重偏好

### 极度看重（核心决策层）

| 指标 | 权重逻辑 |
|------|------|
| **Wyckoff 结构** | **#1 框架**。三大法则：①供给需求法则（量价关系揭示真实供需）②因果法则（吸筹区间大小→后续涨幅大小）③努力与结果法则（放量不涨=派发；缩量上涨=浮筹已清）。不是技术分析，是主力操纵心理学的结构化表达。 |
| **OI 持仓量（区分主力 vs 散户）** | 核心洞察：区分「主力构建的 OI」vs「多头 follow 的 OI」。主力可以单开多制造价格走势，也可以多空双开任意控制方向。「不是你想拉盘就拉盘，你需要对手盘。」OI 的核心功能是识别对手盘蓄水池——空头 OI 堆积=多头挤压燃料；多头 OI 堆积=空头挤压燃料。 |
| **订单簿 / Tape Reading** | limit order（maker）= 阻挡价格的行为 = 供给。market order（taker）= 驱动价格的行为 = 需求。「CVD 一直增加但价格不涨 = 上方有大量 limit order 厚墙。」订单簿深度变化速度 > 深度绝对值。 |
| **链上数据（地址级）** | 交易所冷钱包充值/提现（如 Bitget 0xffa...）、项目方/做市商地址持仓变化、Smart Money 盈亏追踪、DEX 流动性池监控。「RIVER 最近一个月 Bitget 冷钱包新增 723K，BG 是现货出货地址。」 |

### 高度依赖（战术层）

| 指标 | 权重逻辑 |
|------|------|
| **筹码分布/集中度** | 高控筹 = 操盘核心。区分链上吸筹（SIREN 去年开始慢慢吸筹）vs 上所后吸筹。关注 holder 分布和交易所充值/提现地址。 |
| **市场结构/周期** | 判断当前处于牛/熊/过渡期。2025.10 后市场结构完全改变→之前做空躺赚→之后做空必亏。对结构转变的敏感度 > 对单一指标的依赖。 |
| **爆仓/清算数据** | 实时跟踪爆仓量判断挤压力度。「空头爆仓来到 10M+」= 挤压完成。大额爆仓后通常伴随 AR（自动反弹）。 |
| **聪明钱跟踪** | 链上 Smart Money 盈亏追踪。「Smart Money 里亏钱的是做多被套的，赚钱的是谁的仓位？这里都不用想。」 |
| **主力地址追踪** | 项目方/做市商地址的多链行为监控。Wintermute 等做市商介入信号。Solana Token Account 级别的数据追踪。 |

## 3. 交易触发与执行倾向

### 核心理念：认知 = 仓位

> 「赚钱靠的不是百分比，而是你能上多少。上多少取决于你对这个东西的认知，以及你的认知和市场中其他人对这个东西的定价偏差。不确定你敢上很大那就是赌博。确定了上赚钱了这就是符合模型。」

### 四大入场模式

**① Wyckoff Spring/ST 确认入场（最稳定）**
1. 识别大周期 Wyckoff 阶段（日线/4H）
2. 吸筹区出现 SC（放量大阴线后价格得到支撑 → 未知力量消化了抛售）
3. 等待 AR（自动反弹）
4. ST（二次测试）成功 → 缩量不破 SC 低点
5. Spring（震仓）后出现 Higher High → **入场**
6. 「Spring 后的 HH 去做，稳定。」

**② 对手盘挤压抢先入场（最高赔率）**
- 识别对手盘蓄水池：空头 OI 持续堆积 + 多空比极端偏空
- 确认主力多头仓位已建立
- 在挤压启动前跟随主力方向入场
- 「空头蓄水池满 → 主力拉盘爆空 → 跟随做多」
- 「多头 OI 堆积 → 主力砸盘爆多 → 跟随做空」
- 核心：区分「主力自己的仓位」vs「吸引来的对手盘」

**③ 订单簿消化信号入场**
- 监控 limit order 被 market order 消化的速度和量
- 拉升过程中 limit sell 被持续吃掉 → 真实需求在消耗供给 → 趋势延续
- 拉升过程中 limit sell 挂单量增长 → 主力在悄悄出货 → 即将反转
- 「CVD 一直增加但价格不涨 = 上方有大量 limit order 墙」

**④ 主力高位派发 + 弱势反弹入场做空**
- 监控主力高位出货痕迹（价格不跌但指标暴露）
- 等待弱势反弹的次高点（不触及前高）
- 确认 supply > demand → 最小阻力方向向下 → **入场做空**
- 盈亏比极高（离前高很近，止损空间小）
- 「不会去试探最高，更偏向右侧。主力高位派发后，弱势反弹的次高。」

### 真突破 vs 假突破判别

> **「假突破和真突破不是从小趋势去看，从大的趋势去看。」**

| 场景 | Wyckoff 视角 | 操作 |
|------|------|------|
| 吸筹/再吸筹周期 + 突破 | 真突破——吸筹后的拉升启动 | 做多 |
| 派发/再派发周期 + 突破 | 假突破——拿多头流动性 | 做空/不做多 |
| 关键阻力位突破后迅速收回 | 拿空头流动性（price magnet） | 突破做多，到 price magnet 止盈 |

### Price Magnet 法则
> 「90%+ 的首次突破都会突破 price magnet 再收回，拿到这个点位的空头流动性。」

突破关键阻力 → 触发空头止损 → 价格冲到 price magnet → 收回 → 盘整。这是多空双杀的经典路径。

## 4. 风控与退出策略

### 仓位铁律：认知定仓位

> 「不做比做什么更重要——过滤掉 90% 的机会。」

- 确定性高 → 上大仓位
- 认知不够 → 不做 / 极小仓位试探
- 「你带着 YY 的想法和情绪去玩，能理智么？」

### 止损体系

| 止损类型 | 触发条件 | 逻辑 |
|------|------|------|
| **Wyckoff 结构止损** | ST 失败 / 跌破 SC 低点 / 吸筹区被破坏 | 结构破坏 = 主力意图改变 |
| **主力成本区止损** | 价格跌破主力 OI 均价 | 主力已亏→可能放弃护盘 |
| **预期外止损** | 出现未预期的市场行为且无法合理解释 | 「预期外的 case 发生且解释不了 → 迅速止损，切勿扛单」 |
| **移动止盈保护** | 浮盈后移动止损线 | 学习主力模仿欺骗后的应对：「好歹我移动止盈，最后还是止盈的」 |

### 预期管理（进场前必答题）

```
进场前：
a. 你的预期是什么？
b. 有没有想到预期外的 case？
c. 如果预期外 case 发生如何应对？
   → 离场？
   → 能合理解释这种行为？
   → 解释不了 → 迅速止损，切勿扛单

进场后（在预期内）：
d. 止盈是什么？→ price magnet 首次突破止盈
e. 趋势反转信号？→ supply > demand 确认
```

### 杀猪盘识别 = 最高优先级风控

- 盘口极浅（10wU 仓位即可插飞几个点）
- OI 双向都大（多空双杀结构）
- 操盘手法极暴力（如 TRADOOR：1 小时上下 165%）
- **→ 直接跳过，不参与，不看。「一个合格的交易员看到这种盘面都不会去赌的。」**

### 持续进化体系

```
交易 → 复盘 → 反思认知偏差 → 更新模型 → 
因子验证 → 数据层→规则引擎→触发器自动化 → 
操盘特征→肌肉记忆→下一次更快识别
```

> 「主力模仿了上次下跌的过程，然后突然反转，导致大面积浮盈迅速撤退。这次主力欺骗的 case 我学会了，记录了，下一次继续学。」

### 交易心法

> **「wyckoff 从来不是一本技术分析的书。最后我才明白，wyckoff 核心的用途是主力对于散户内心的操纵。一根根 K 线上/下引线背后其实是 FOMO 和 Fear 的完美写照。」**（2026.03，三年 Wyckoff 研究总结）

> **「流动性和对手盘，永远是操盘者眼里的第一要务。」**

> **「赚钱靠的不是百分比，而是你能上多少。上多少取决于你对这个东西的认知，以及你的认知和市场中其他人对这个东西的定价偏差。」**（2026.05）

> **「交易这件事，能真正坚守住自己本心的很少。基本面变了吗，其实没变。越跌越开心，因为最初的选择已经做足了多方面多因子的交叉验证。」**（2026.05）

> **「不做比做什么更重要。玩确定性高的，迭代自己高赔率的玩法，持续优化，形成正反馈。」**（2026.05）

> **「AI 本身不能产生策略，AI 只是提高你的生产效率。如果你的策略能盈利 1000U，AI 可以给你放大到 10wU。」**（2026.04）

> **「真正猛的爆拉前一定是虐你千百遍，洗走大部分人，弱的让你怀疑人生，这才能达到其对应的效果。」**（2026.05）
