## 一、VC币/Alpha币四分类法

> 「VC币/alpha币研究，可以做几个分类，考虑清楚自己擅长的点，哪种路径更适合自己，集中主要精力在自己擅长的领域创造最大的财富」

### 1.1 类型一：已上币安现货
- 前期因为抛压问题会跌 → 做空机会
- 跌无可跌时 → 建仓，赌上韩国所和二段的机会
- 案例：$KAT

### 1.2 类型二：Alpha上新标的
- 根据基本面和链上数据，低开盘买入
- 赌上币安合约和韩国所合约的机会
- 案例：$PRL

### 1.3 类型三：MM操盘庄币
- 赚钱比较难
- 观察OI、爆仓数据、操盘手法
- 特点：通过合约爆多爆空的方式赚钱
- 案例：$SIREN

### 1.4 类型四：拉高现货派发筹码
- 根据K线走势，玩波段的方法去赚钱
- 案例：$CYS $COLLECT

## 二、MM行为模式

### 2.1 MM拉盘-诱空-爆空完整循环

> 「mm一般首先通过拉盘，拉到涨幅榜，让更多的人注意到这个标的，横盘策略，吸引和积累更多的空单进来，让空军误以为拉不上去要下跌的假象」

循环步骤：
1. 拉盘到涨幅榜 → 吸引市场注意力
2. 横盘 → 积累空军（空军以为拉不上去要下跌）
3. 多军跟车过多时 → MM砸盘爆掉多单
4. 多单爆掉、空军越来越多 → 开启新的拉盘，吸引更大空头
5. 参考$SIREN：拉盘爆掉750多万的空单 → MM撤多单暴跌 → 再诱空

> 「这过程中会有不少多军进来跟mm的车，如果空军没有加仓，而多军又越来越多，这时候mm也会采取爆多单的方式砸盘爆掉多单」

### 2.2 MM的三种赚钱手法

> 「VC币只剩下了mm，赚钱手法无非几种方式」

**手法一**：开好多单 → 拉盘 → 吸引空军开空 → 爆空单
**手法二**：拉到一定市值 → 开好空单 → 在二线所砸现货 → 一根大阴线
**手法三**：试拉盘 → 猛然砸盘洗掉多单跟单 → 上下插针洗盘

> 「过程中，怕韭菜跟多单，会通过试拉盘然后猛然砸盘的方式洗掉多单的跟单，过程中也会通过上下插针的方式洗盘」

### 2.3 洗盘模式

**扯多单洗盘**：
> 「通过扯多单的方式把1倍杠杆的仓位都能爆掉，洗完跟车的多单车轻了，一堆人又进去做空了，庄的目的就是爆空单」

**底部筹码洗盘**：
> 「一堆人都以为是底了，一堆人一起建仓的，这时候，庄大概率会砸盘洗掉这些人再考虑拉盘，这个时间可能需要很久」

**边拉边洗**：
> 「这个mm操盘的风格是拉一下回调洗一下，再继续拉，再洗」

### 2.4 主动MM vs 被动MM

> 「做市商分成2类，一类是被动mm，一类是主动mm」

- **被动MM**：提供一定流动性，帮项目方卖货。盘面难看，卖不了多少货，被全市场骂。
- **主动MM**：通过控制K线爆空单、多单、出货等方式赚钱。有的温和（慢慢拉砸k线），有的暴力（太离谱容易被币安风控）。

> 「项目方一般不听任何人的，无论是顾问还是mm，也不看市场，总觉得自己项目好……直到发现盘面很难看，也卖不了多少货，还被全市场骂；这时候就会考虑换主动mm来做市值管理了」

## 三、OI与合约数据判断

### 3.1 OI真假辨别

> 「很多oi的数据可能是庄多空双开的，并不是对手盘开的。如何判断OI数据的真假，结合全网的多空爆仓数据来看」

| OI特征 | 爆仓特征 | 判断 | 操作 |
|--------|---------|------|------|
| OI很大 | 全网爆仓极小 | 庄多空双开（造假OI），吸引散户上车多空双爆 | 回避 |
| OI干净 | 爆仓真实 | 多单庄为主，目的爆空，逻辑合理 | 跟多单 |

> 「如果oi很大，但是全网的爆仓数据很小，这可能是矛盾的，大概是庄自己多空双开」

> 「像那种比较干净的oi：多单庄为主，目的是为了爆空，这种拉盘逻辑是比较合理的，会给跟车的散户多单惊喜」

案例：$BANANA31 OI 38.8m、多空比135.36%、全网多空爆仓极小 → OI造假
案例：$RIVER $SIREN OI数据相对干净、真实性大

### 3.2 OI-价格关系

- OI↑ + 价格↑ = 真趋势，多头主导
- OI↑ + 价格↓/横盘 = 洗盘诱空，庄在吸筹
- OI↓ + 价格↓ = 多头离场

### 3.3 多空比极端反向

> 「$Rave大户多空比账户数达到了0.27，也就是说假如100个合约账户数，79个账户做空，21个账户做多，而庄的目的就是爆空单」

- 多空比极端时反向操作
- 多空比容易被喊单改变 → 喊单一堆人做多就要被干 
- 「喊单改变多空比，mm就杀多了」

### 3.4 资金费率信号

> 「资金费率是做交易的一个核心指标，关系到两点：一是代表市场情绪，二是直接关系到你的交易手续费」

- **正费率**：合约价>现货价，市场看涨情绪强
- **负费率**：合约价<现货价，市场看跌情绪强
- **极度负费率** → 做多机会
- **负费率在变小** → 警惕庄家在平多单或出现货

实战案例：
> 「mc超过1亿市值肯定是高估的，这个时候就是一个非常好的开空的机会，等到资金费率为负值且绝对值变大的时候，就可以平仓了，这个机会是稳赚的」

**跨交易所套利**：A交易所费率0.001%、B交易所费率0.005% → 在A做多、B做空赚费率差 

### 3.5 合约/现货成交量比

> 合约/现货成交量比大于3倍时，上涨通道确认，做多信号

案例：
> 「$ALCH #Broccolif3b #Fartcoin都有一个共同的特点，就是合约交易量远远大于现货交易量」

## 四、庄成本建仓法

### 4.1 多单成本安全边际

> 「你的入场价格越接近mm的平均多单成本越安全」

- 看合约上庄的多单成本价 → 无限接近该价格是健康抄底位置
- 案例：$UB庄多单成本0.125u；$BILL庄多单成本0.1u 

### 4.2 空单成本判断下跌

> 「看合约持仓，多单和空单的建仓价格，如果下跌趋势已成了，空单会盈利越来越多，看下空单建仓的成本价格，就大概可以判断出来庄建空单的成本，而空单一直没撤，盈利越来越多，那么就是庄出货+建好了空单」

## 五、收网信号识别

> 「找到项目方收网的信号是最重要的，这样你才敢空进去」

五个核心指标：
1. **OI变化**：多单在减少、空单没什么变化、整体OI在降 → 庄多单在撤，变相砸盘
2. **资金费率**：费率在变大，尤其是变成负费率 → 可能是变盘的开始
3. **现货砸盘**：看该标的现货在什么CEX（一般庄币现货在Gate/BG，币安合约为主），是否有地址转入和砸盘
4. **市值参考**：有一定参考性
5. **庄头寸方向**：猜测庄的多空头寸在哪边

> 「最重要的几个指标还是看oi变化，猜测庄的头寸在哪边」

## 六、Alpha三段锦出货法

> 「币安alpha的项目出货可以分成三段锦」

### 一段锦：首发建仓
- Alpha首发开盘时底部入手 → 建头仓
- 在庄反复洗盘过程中拉低均价
- 市值稳住后庄拉盘 → 有1-2x利润 → 出本+留部分利润
- 等待币安合约和韩国所消息（短则2-3天，慢则1周）

### 二段锦：合约上线
- 等来币安合约 → 市场情绪fomo时出部分货
- 上线合约时如没有拉升迹象 → 全部出掉或留底仓

### 三段锦：观察后续
- 无韩国所消息 → 市场情绪降到底部 → 该出的都出了
- 如庄没有继续护盘迹象 → 全部出掉
- 后续可关注：持续洗盘和新低，参考私募轮价格

## 七、回调vs下跌判断四法

> 「如何判断是回调还是一路下跌呢？」

1. **看K线走势**：有没有反弹的迹象
2. **看链上出货**：有没有一直出货的账户，盯是不是在一直出货
3. **看合约持仓**：空单建仓成本 → 空单一直没撤+盈利越来越多 = 庄出货+建好空单
4. **看交易所充值**：现货是不是充值进去出货了

## 八、Alpha低开盘买入法

> 「强庄不墨迹，因为是低开，抛压砸盘后很快拉盘，为什么呢？不想在底部给散户买低筹码的机会，要不然后续拉盘车太重」

- 低开盘（FDV低于3000万）→ 果断买入
- Alpha空投抛压（1%筹码）结束后 → 最佳低价筹码时间窗口 → 出手要果断
- 「alpha的0.5%的筹码抛压结束后，喊社区的人上车，这就是最佳的低价筹码的时间窗口」
- 高位3x收益 → 出本后利润蹲上币安合约

## 九、链上出货行为追踪

> 「项目方发项目的根本目的是为了出货，了解清楚庄的出货行为是每个合格韭菜的基本功」

### 9.1 大市值项目出货方式
- 转出到新钱包 → 多转几道再出货
- 不直接在原地址出货（会被直接显示出来）
- 通过转出地址出货，不影响前排地址的盘面

### 9.2 小市值项目出货方式
- 大号钱包地址不动（如前100地址不动）
- 小号出货

### 9.3 三种典型盘面判断

- **$CYC**：上Alpha后链上基本无自然买盘，庄在刷量+顺带出货
- **$GOR**：庄有实力，刷量较大，几个大户地址建仓
- **$QR**：交易量小、市值创新高但承载不了大资金，庄一边拉盘一边出货

## 十、Meme筹码分散策略

> 「大家购买代币，要分钱包，每个钱包最多不要超过1%，甚至越分散越好，一方面有利于增加持币地址的数量，另一方面不至于被庄盯上去洗掉你」

> 「如果你的筹码过于集中又很大的话，庄一定是想办法洗你，车轻了好拉盘呀」

- 分3-4个钱包，每个不超过1SOL
- 分散钱包让前排筹码更健康、更分散
- 后面的人看到健康的筹码分布才敢买，庄也愿意进来

## 十三、上币判断

> 「上币标准是：热度+关系，你是实在亲戚，我就可以给你上」

- Alpha项目上合约的目的：为了出货；不上合约，alpha和链上很难出货 
- 上合约后：1.2亿左右市值上合约 → 市场买盘几乎没有 → 庄不拉盘（拉盘成本高）→ alpha现货+其他所现货+币安合约足够完成出货 → 一边出货一边开空 
- 「有了合约在币安，就是个金铲铲，韭菜养养就可以再出一波货了」
