## 零、进场前置：合约类型识别（先做这个）

进场前先判断这个币的「合约身份」，不同身份对应完全不同的做盘逻辑：

### 0.1 alpha+合约（仅合约，高控，大概率不上现货）
**特征**：链上前10地址持仓 > 90%、场外流通极少 
**做盘逻辑**：高控 → 拉盘爆空 → 拉高派发出货。不会上现货（现货要交筹码）
**可操作信号**：
- 识别 MM 洗盘节奏：一直拉盘 → 直接砸盘洗多单 → 再拉盘吸引空军 → 定点爆破 
- OI > MC 市值 → 妖币结构正在形成 
- 盯爆仓数据：看上方空军位置，有空军就拉盘定点爆破 

### 0.2 alpha+合约→上现货项目
**特征**：团队+机构背景强、跟币安关系好、上了合约后阴跌不拉盘 
**做盘逻辑**：项目方在低价接筹码 → 上现货交筹码 → 庄出货+开空单 → 等韩所再拉一波出货 
**可操作信号**：
- 上线后阴跌+没有爆拉动作 = 项目方在低价吸筹（上现货预期）
- 上现货后一般慢慢阴跌（庄出货+合约空单已开好）

### 0.3 已上现货项目
**逻辑**：筹码控筹分散 → 非妖币逻辑 → 适合波段而非追爆空

## 一、进场信号清单（逐条对照盘面数据判断）

每条信号标注可查询的数据来源和 Arya 的原文判断逻辑。

### 1.1 OI-价格四象限（核心层）

| 盘面表现 | Arya判断 | 方向 | 出处 |
|----------|----------|------|------|
| OI↑ + 价格↑ | 真趋势，多头主导 | 做多 | |
| OI↑ + 价格↓/横盘 | 洗盘诱空，庄在吸筹，"洗完跟车的多单车轻了，一堆人又进去做空了，庄的目的就是爆空单" | 准备做多 | |
| OI↓ + 价格↓ | 多头离场，趋势转弱 | 回避/做空 | |
| OI↓ + 价格↑ | 空头撤退，逼空进行中 | 谨慎追多 | |


### 1.2 多空比极端反向（核心层）

- 多空账户比极端 → 反向操作 
- 多空比是市场情绪的滞后指标，且容易被喊单改变 → 喊单一堆人做多就要被干 
- 「喊单改变多空比→MM反向杀」：需判断当前多空比是自然形成还是人为干预 


### 1.3 资金费率信号

- **极度负费率** → 做多机会 
- **负费率在变小** → 警惕：庄家在平多单或出现货 
- 费率需与 OI 共振才有效：单独看费率容易误判 


### 1.4 合约/现货成交量比

- 合约/现货成交量比 > 3x → 上涨通道确认，做多信号 
 （注意：这是 Arya 原文明确的数字阈值）


### 1.5 庄多单成本建仓法（2026 新增核心方法论）

- 「入场价格越接近 MM 的平均多单成本越安全」
- 看合约上庄的多单成本价在什么位置，无限接近多单成本价是健康抄底位置 
- 实际案例：$UB 庄多单成本 0.125u → 接近该价格是抄底好位置；$BILL 庄多单成本 0.1u 
- 反用：看空单建仓成本，空单一直没撤+盈利越来越多 → 庄出货+建好空单 


### 1.6 左侧 vs 右侧入场选择

- **二段币**：必须在右侧趋势确认后追入。不要在下跌中接（"接的是飞刀，会比较难受"）
- **波段币**：大跌抄底、大涨卖出、坚决不追高。看 K 线区间，顶部和底部相差 50%-5x 
- **底部埋伏**：适合有耐心者，但注意「一堆人都以为是底一起建仓→庄砸盘洗人再拉盘」
- **alpha 低市值埋伏**：MC 接近合约壳子价格 + 历史上多次爆拉过 

### 1.7 叙事驱动选币

- 赛道优先：先选赛道再选项目 
- 每个赛道只做最确定性的 1-2 个项目 
- 「叙事轮动」：市场不是随机波动，是叙事驱动的；每个周期有主导叙事 
- alpha+合约项目的基本面研究正在失效 → 更重要的变成：盯项目方地址是否出货 
- 低市值开盘 + 高控 + 冲合约预期 = 项目方有动力拉盘

## 二、否决信号（出现以下任一 → 跳过/观望）

以下信号是 Arya 明确表达的「不做/回避/警惕」态度，出现任一即应否决进场：

1. **开盘市值过高**（几个亿 FDV 开盘）→ 项目方没动力拉盘，肯定要出货 
2. **项目方地址在持续出货** → 立即回避 
3. **底部埋伏筹码过多**（跟庄抢筹）→ 庄可能不拉盘或重新暴力洗盘 
4. **二线所只有 kucoin + mexc** → 未搞定主流二线所，实力存疑 
5. **在做空大 V 喊单时做多** → MM 最喜欢名牌做空的作为燃料 
6. **逻辑破坏** → 无条件离场

## 三、出场/止盈信号

### 3.1 波段止盈
- 涨幅榜单就逐步卖，跌幅榜单就逐步抄底 
- 「底部买 + 买的多 + 等到拉升的机会 = 赚钱」

### 3.2 妖币止盈
- 盯链上庄的地址：庄出货 → 跟着出 
- 一段上涨停滞 + 庄没有大笔买入动作 → 轻仓一段利润，等二段 
- 「鱼尾不参与，没人从头吃到尾」— 利润够了就出 

### 3.3 止损规则
- 每次必设止损，无止损不下单 
- 「趋势不对可以先下车，等走势明朗再决定上车还是下一个」
- 「设置一个心理止损线，跌破了就要割肉」

|------|------|------|

## 五、MM（做市商）行为速查手册

Arya 的核心方法论是「识别庄的意图并跟随」。以下是推文中反复出现的 MM 行为模式：

### 5.1 拉盘目的三分类
1. **爆空**：合约上空单多 → 拉盘定点爆破 
2. **做事情/吸引注意力**：鼓励生态发展、吸引市场目光 
3. **拉高出货**：高位派发筹码 

### 5.2 洗盘模式识别
- **模式 A（妖币前洗盘）**：一直拉盘 → 直接砸盘 50%+ → 洗掉多单 → 再拉盘吸引空军 → 爆空 
- **模式 B（底部埋伏被洗）**：底部筹码多了 → 庄砸盘重新洗 → 增加数周洗盘时间 → 才拉大阳线 
- **模式 C（波段 MM）**：拉一下 → 回调洗一下 → 继续拉 → 再洗 

### 5.3 妖币形成信号
- OI 持仓 > MC 市值 
- 全网合约成交量持续放大 
- 出现巨鲸爆仓（百万级 USD）→ 确认妖币属性 
- 「还没形成妖币的结构」= OI 相对 MC 还不够大 + 爆仓金额不高 

### 5.4 庄意图验证三问
1. 庄有没有在链上出货？→ 出货就跟着出 
2. 拉盘的目的是什么？→ 爆空 / 冲合约 / 拉高出货 
3. 庄的多单/空单平均成本在哪里？→ 决定入场安全边际

## 六、进场决策速查流程（给 LLM 的 step-by-step）

```
Step 1 → 判断合约身份（0.1/0.2/0.3），确认做盘逻辑
 ├── 仅合约高控 → 继续 Step 2（爆空逻辑）
 ├── alpha+合约→现货预期 → 判断是否在低价吸筹阶段
 └── 已上现货 → 仅适合波段，不适合追爆空

Step 2 → 查否决信号（第二章），有任何一条命中 → SKIP

Step 3 → 查 OI-价格四象限（1.1）
 ├── OI↑+价↑ → 做多信号 ++
 ├── OI↑+价↓ → 潜在洗盘诱空，观察等反转
 └── 其他组合 → 谨慎

Step 4 → 查多空比+费率极端（1.2 + 1.3）
 ├── 多空比极端 + 负费率 → 做多信号 +
 └── 费率正常 + 多空比中性 → 无额外信号

Step 5 → 查庄成本安全边际（1.5）
 ├── 当前价接近 MM 多单平均成本 → 做多信号 ++
 └── 当前价远离庄成本 → 追高风险

Step 6 → 确认入场方式（1.6）
 ├── 右侧趋势明确 → 可以追
 ├── 大跌到波段底部 → 现货抄底（不玩合约）
 └── 左侧阴跌中 → 等待，不接飞刀

Step 7 → 综合评分 → ENTER / WAIT / SKIP
```

## 七、核心原则（定性注入 System Prompt）

以下为 Arya 原文中最具代表性的认知框架语句，可直接作为 LLM 的思考锚点：

- 「市场不是随机波动，是叙事驱动的」 
- 「合约市场本质是 MM 与散户的对赌；庄家控制盘面，散户要做的就是识别庄的意图并跟随」 
- 「不做比做什么更重要」 
- 「每一次拉升都是为了爆空单」 
- 「现在币圈的很多项目，都不要看基本面了，就看庄的操盘手法」 
- 「入场价格越接近 MM 的平均多单成本越安全」 
- 「底部埋伏过多筹码 → 庄砸盘重新洗」 
- 「我们靠什么赚钱，要清楚自己的位置：我们都是普通人」 
- 「永远不要想卖在最高点」
