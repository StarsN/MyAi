## 1. 核心交易情境

### 偏好环境
- **信息不对称市场**——核心驱动力。币圈的本质是信息不对称市场，超额收益来自比别人更早发现定价偏差。「定价偏差 = Alpha，与市场共识的偏差越大，潜在收益越高。」擅长发现生活中的 Alpha，但不擅长精确价格点位判断。
- **NFT Strategy 飞轮生态**——深度参与 @token_works / @Rhynotic 的链上 DAT 创新。PNKSTR 从 2M 涨至 330M。核心机制：国库以高于市价挂单购买资产 → 手续费复投 → 市值增长 → 飞轮加速。「最好的投资标的是那些'只要有人交易就能自动增长'的系统。」
- **Hyperliquid 聪明钱追踪**——通过 @echosync_hq 等 AI 工具分析链上顶级交易员的实时操作。「通过 AI 和 Hyperliquid 的纯链上数据，我可以换一个方式来构建自己的投资体系。」不再被动看 K 线，而是主动学习聪明钱策略。
- **Polymarket 关联事件套利**——非方向性押注。事件 A 的发生概率传导至事件 B 的定价。「天气预测 → F1 雨战冠军 → 适应雨战的车手」。AI 辅助跨领域信息处理形成信息优势。
- **MM 做市商之春**——2026 年初提出的交易范式。做市商寻求买币安合约壳（供给端需求）→ 选择「鱼多」标的 → 币安广场是最优质的鱼塘 → 广场数据 = 链上资金流动的舆论版。

### 回避环境
- **纯技术分析 / K 线交易**——「我不太懂二级交易，也看不懂 K 线。」不依赖图表，依赖信息优势和机制理解。
- **频繁短线操作**——「我宁愿面对回撤和波动也不愿意频繁操作而增加容错的几率。」长尾持有者，钻石手。
- **没有信息优势的领域**——对价格不敏感，对信息敏感。没有信息差的标的 = 不参与。

### 策略进化路径（六阶段）

```
港美股壳股交易员 → 链上 PVP 博弈 
→ NFT Strategy 飞轮（PNKSTR 330M）
→ Polymarket 预测市场套利
→ Hyperliquid 聪明钱跟单 + 生态建设
→ AI 工具链（Claude 写脚本/100U→48KU 实验）
```

「不执着于单一策略，永远寻找下一个信息不对称洼地。」每进入一个新领域享受低竞争红利，竞争者涌入后转移。

## 3. 交易触发与执行倾向

### 核心理念：信息差 = Alpha

> 「币圈是一个信息不对称市场。超额收益的关键不在于技术分析能力，而在于更早地发现信息、更准确地解读信息、更快地行动。」

**不依赖 K 线，依赖认知差。**

### 五大入场模式

**① NFT Strategy 飞轮建仓（最高仓位）**
- 识别飞轮机制：合约能否自动永续执行？（Punk ✓ / 721 ✗）
- 关注开盘机制：95% 递延税 → 狙击手和项目方成本都在 1M+ → 安全边际高
- 计算成本曲线：开盘瞬时 20 倍 → 5 分钟 10 倍 → 20 分钟 5 倍 → 结合当前市值判断
- 监控飞轮转速：国库资金量、Punk 持有量、日成交量（策略手续费 1% 回流 PNKSTR）
- 「每天都有大户砸一笔，每次被砸了后都被买上来——持仓体验极好。」

**② AI 脚本 + MM 之春策略（AI 自动化交易）**
- 100U 启动 → 8 天 480X → 4.8 万 U（实验性质）
- 脚本逻辑：
  1. 抓币安广场流量最高帖子 + 帖子量最高币种（区分 bot/真人）
  2. 涨幅榜找异动标的 → 追高（主动 MM 不会只拉几十个点）
  3. 优先过去半年新币或有过大幅波动的币
  4. 观察 48h OI 变动大但价格没反应的标的
  5. 买入时挂止损（从 20% 优化到固定 200U 亏损）
  6. 蒸馏自己 Twitter + 钱包 → 模拟链上打法
  7. AI 自动化发广场、截收益图

**③ 叙事前置布局（信息优势模式）**
- IP 周年庆前布局 → 如 CZ 出书「币安人生」叙事
- 体育赛事大年前预判 → F1 雨战、世界杯等
- AI Agent + 游戏 IP 结合 → 寻找叙事叠加
- 「第一个被交易所选择的标的有重要意义。」

**④ 聪明钱跟单策略（学习型入场）**
- echosync AI → 搜索「适合 5000U 起步的地址」→ 找胜率高/盈利倍数高的
- 分析交易员操作风格 → 多空切换节奏 → 组合跟单
- 核心：发现自己二级交易短板（不会做空对冲 + 不会利用杠杆 + 只会扛单）→ 让 AI 帮找老师

**⑤ Polymarket 关联事件套利**
- 事件 A 概率变化 → 事件 B 定价调整
- 天气预测 → F1 雨战冠军 → 适应雨战的车手
- AI 辅助跨领域信息检索 → 比市场更快发现定价传导
- 非方向性，寻找「市场的定价错误」

### 跟 Bot / 策略机器人博弈

> 「博弈已经不仅仅是人之间 PVP 的博弈，更多的机会存在于与链上策略机器人的博弈。」

- 研究最大策略机器人的策略 → 预测其进场条件 → 通过交易行为触发他们进场
- 类比港美股壳股时代：通过交易行为吸引量化基金进场获利

## 4. 风控与退出策略

### 仓位管理：1-5% 高确定性，≤1% 投机

| 确定性级别 | 仓位 | 案例 |
|------|:---:|------|
| 高确定性（机制飞轮） | 1-5% | PNKSTR 长期持有 |
| 中确定性（叙事/上币预期） | 1-3% | HYPE 持续囤积 |
| 投机（高风险可能归零） | ≤1% | MITCH 等 |
| AI 实验 | 100U 起步 | MM 之春脚本测试 |

### 止损体系

| 止损类型 | 触发条件 |
|------|------|
| **AI/脚本止损** | 固定金额止损（200U）或百分比止损（20%），由 AI 自动执行 |
| **飞轮减速预警** | 国库资金异常流出、Punk 策略停止执行、成交量持续萎缩 |
| **归零风险接受** | 1% 投机仓位接受归零可能——「风险极高可能归零」 |
| **策略迁移** | 竞争者涌入 → 寻找下一个低竞争领域。不执着一城一池 |

### 钻石手哲学

> 「我是一个针对标的价格不敏感的人。我对于盈利和亏损没有概念。我宁愿面对回撤和波动也不愿意频繁操作而增加容错的几率。我习惯吃长尾市场而不是胜率更高的一段。」

- **不追求精确点位**：「我不太懂二级交易，也看不懂 K 线」
- **长尾持有**：「我目前一个币还没卖出，你们呢」（PNKSTR 从 2M 到 330M）
- **接受巨大回撤**：「享受从 0-100 的快感，也不得不体验从 100 回撤到 30 的痛苦」
- **核心信念**：如果你判断对了机制和叙事，时间会站在你这边

### 止盈/退出

| 触发条件 | 动作 |
|------|------|
| **共识最一致时退出** | Spot 阶段（所有人都知道要上币安）= 退出窗口 |
| **飞轮机制失效** | 合约无法自动执行 / 国库被掏空 = 立即退出 |
| **竞争者涌入** | 策略优势消失 → 迁移到下一个低竞争领域 |
| **叙事兑现** | 事件落地 → 预期变为事实 → 利好出尽 |

### 策略进化铁律

> **「不执着于单一策略，永远寻找下一个信息不对称洼地。」**

```
港美股壳股 → 链上 PVP → NFT 策略 → 预测市场 → Hyperliquid → AI 工具化
   ↓ 竞争涌入         ↓ 竞争涌入        ↓ 竞争涌入      ↓ 下一站
```

「AI 工具可以加速这个迁移过程。」

### 交易心法

> **「AI 是很好的学习工具，但是要自己把握好风险。我这波是运气占 90%，第一笔交易就打下资金垫，换一个行情来应该就失效了。」**（2026.04，AI 脚本 480X 实验）

> **「币圈是一个信息不对称市场，超额收益的关键不在于技术分析能力，而在于更早地发现信息、更准确地解读信息、更快地行动。」**

> **「最好的投资标的是那些'只要有人交易就能自动增长'的系统。」**（NFT Strategy 飞轮）

> **「我是一个很擅长发现生活中 Alpha 的人。但我是一个针对标的价格不敏感的人——我宁愿面对回撤也不愿频繁操作。」**（2026.01，年终总结）

> **「做市商的行为是可预测的，他们的入场信号隐藏在广场数据和合约壳交易中。」**（MM 之春理论）

> **「在 Hyperliquid 之前我没有太多机会去学习真正的聪明钱是如何交易的。现在通过 AI 和纯链上数据，我可以换一个方式来构建自己的投资体系。」**（2025.12）

> **「活在链上久了原来我才是被困在井底的那只蛙。」**（2026.02，回老家后发现老登们都在聊 SpaceX 和太空算力）
