# Arya_web3 交易员认知快照

## 1. 核心交易情境

### 偏好环境
- **币安 Alpha 上新**——**第一主战场**，胜率自评 95%+。核心逻辑：低 FDV 开盘 + 低流通 + 强做市商 + 币安合约预期。Alpha 项目选择标准：项目方有钱/有资源（非纯社区盘）、二线所覆盖广（BG/Bybit/Coinbase 级别）、叙事卡位清晰。不上合约则无法出货，因此"alpha+合约"是最佳信号组合。
- **庄币（MM 控盘代币）**——识别做市商是核心能力。区分被动 MM（仅提供流动性、帮项目方卖货）与主动 MM（控制 K 线、爆空爆多、拉砸循环）。主动 MM 介入 = 跟车机会；被动 MM = 只卖不拉，不碰。
- **强庄 meme + 顶级社区**——低市值阶段给足社区上车时间（3-5M 横盘 1 个月换手）、有灵魂人物（车头）+ 机构/KOL 明牌支持。筹码完成从散户→巨鲸→机构的逐级换手。
- **赛道叙事窗口**——AI、RWA、DePIN、meme 四大赛道。叙事萌芽期埋伏龙头，币安合约上线后利好兑现分批退出。

### 回避环境
- **合约高杠杆**——"很少看到玩合约赚到大钱的人"。现货为主，合约仅用极小杠杆+大保证金+高盈亏比位置。
- **高 FDV 开盘 + 无锁仓 + 无强 MM**——大概率派发而非吸筹，二级抛压巨大。
- **项目方自作聪明**——广撒网找 MM、公开卖壳、"总以为自己是市场上最聪明的人"的项目方，直接回避。
- **纯社区 meme 无机构/MM 介入**——除非有灵魂人物+顶级车头，否则一波流。

## 2. 微观指标权重偏好

### 极度看重（核心层）

| 指标 | 权重逻辑 |
|------|------|
| **做市商行为 / MM 识别** | **#1 指标**。被动 MM = 帮项目方卖货（回避）；主动 MM = 控制 K 线爆仓获利（跟车）。判断方法：K 线拉砸风格是否暴力、是否有资金在关键位护盘、砸 50% 后是否继续下跌。MM 是庄币唯一的价值支撑——MM 走 = 归零。 |
| **FDV / 市值 / 流通量** | 估值锚定核心。FDV < 50M + 低流通 = 安全边际；龙头不设硬上限（"确定是龙头，无所谓贵不贵"）。重点关注：融资额 vs FDV（如融资 60M、FDV 40M → 严重低估）。 |
| **爆仓数据** | 实时追踪爆仓金额。大额空单爆仓后 MM 通常撤多单 → 价格回落。爆仓数据是判断"MM 目标是否达成"的关键——爆完即撤。 |
| **币安合约预期** | Alpha 项目的核心催化剂。没有合约预期 = 无法出货。合约上线 = 利好兑现、退出窗口。 |

### 高度依赖（辅助层）

| 指标 | 权重逻辑 |
|------|------|
| **筹码结构 / 解锁** | 低流通 + 高锁仓 = 二级抛压极小。1% 巨鲸完成建仓 + 机构明牌 = 筹码结构健康。关注早期获利盘是否完成换手。 |
| **叙事 / 赛道卡位** | 先判断赛道叙事空间，再选龙头。AI+DePIN、RWA 等赛道优先。"不买叙事已过顶峰的标的"。 |
| **K 线 / 价格行为** | 右侧确认工具。砸 50% 后不继续跌 + 横盘数日 = 可能在走二段（$RAVE 剧本）。突破后横盘不跌 = 真突破；突破后快速回落 = 流动性吸收。 |
| **OI 持仓量** | 辅助判断 MM 意图。OI 坚挺 + 价格下跌 = 主力未走（洗盘）；OI+价格双杀 = 真出货/多头踩踏。 |

### 忽视/蔑视
- **精确技术指标**——不纠结精确买点，"先上底仓，不要因为一直等回调错失暴涨的机会"。
- **短期价格噪音**——"买入装死，等待庄或者野庄搞事情"。

## 3. 交易触发与执行倾向

### 右侧切入（主力模式）
1. **Alpha 低开买入**：FDV < 50M + 低流通 + 有币安合约预期的标的，开盘即建底仓。不纠结精确买点，先上车。"研究明白看好的项目，先上底仓"。
2. **龙头确认追入**：龙头启动后第一时间建底仓，不登回调。"龙头就是龙头，共识强+强庄+叙事卡位"。
3. **MM 洗盘后二段介入**：庄砸盘 50%+ 后不继续跌、横盘数日、OI 未崩塌 → 可能走二段。在横盘阶段建仓。
4. **机构/KOL 明牌信号**：顶级机构（a16z 等）+ 顶级 KOL 明牌支持 = 加速建仓信号。

### 左侧接飞刀（辅助模式）
1. **基本面深度低估**：融资额远高于 FDV + 币安合约已上 + 未拉过盘 + K 线筑底。分批建仓，"这个赔率还是不错的"。
2. **FUD 逆向建仓**：监管调查、负面 FUD 时逢低买入龙头（如 $HYPE 被调查："资本主义的调查就是给你低价建仓的机会"）。

### 真突破 vs 假洗盘判别
- **真二段**：砸盘 50%+ 后企稳不跌 + OI 维持 + 有 MM 在场证据 → 建仓。
- **假突破**：价格短暂突破后快速回落 + 无增量资金 → 诱多。
- **洗盘 vs 出货**：砸盘后横盘 + OI 坚挺 = 洗盘；砸盘后持续阴跌 + OI 萎缩 = 出货。

## 4. 风控与退出策略

### 退出触发
| 触发条件 | 动作 | 逻辑 |
|------|------|------|
| **币安合约上线** | 分批止盈 | 利好兑现，主力借流动性出货 |
| **MM 离场信号**（币安下架合约、OI 持续崩塌） | 立即清仓 | MM 是庄币唯一价值支撑 |
| **情绪高潮**（媒体刷屏 + 社区 FOMO + 价格加速上涨） | 分批清仓 | "买在无人问津时，卖在人声鼎沸时" |
| **基本面恶化**（项目方弃盘、团队出走） | 无条件斩仓 | 不跟"傻逼项目方" |
| **融资额 vs FDV 倒挂修复** | 逐步减仓 | 估值回归合理区间 |

### 仓位管理
- **现货为主，小杠杆为辅**——合约仅用极小杠杆 + 大保证金 + 高盈亏比位置，"先保证不爆仓，再考虑怎么从庄手里赚钱"。
- **1000u 滚仓法**：全仓买一个高确定性标的 → 翻倍 → 利润再投下一个。不分散。
- **现货必设止损**——"即使是现货也要设置止损，避免被一个币套牢"。
