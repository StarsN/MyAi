## 1. 核心交易情境

### 偏好环境
- **宏观事件驱动**——核心引擎。每一次重大交易必有完整的宏观推理链。「一切经济政策的目的总是为了政策服务」——从政策制定者动机出发，而非表面数据。交易前必须回答：市场在交易什么预期？谁在制造这个预期？制造这个预期的目的是什么？
- **OKX 全产品线深度使用**——主战场。合约、现货、期权、DCD（双币宝）、信号策略、集合竞价、盘前交易、抄底宝。「能在同一平台完成从建仓到对冲到套利的所有操作。」
- **盘前市场博弈**——独门绝活。在 Aspecta (ASP) 等盘前平台寻找定价偏差，利用集合竞价规则套利，识别机构成本区与散户情绪区之间的预期差。
- **预期差（Premium/Discount）**——核心 alpha 来源。寻找「市场定价 vs 实际结果」之间的偏差，而非追逐已定价的叙事。降息预期≠降息；ETF 通过预期≠ETF 真正通过时的价格。

### 回避环境
- **流动性枯竭期**——熊市底部不做左侧重仓，等待博弈最激烈时刻再选择
- **纯情绪驱动**——不对 FOMO/FUD 做反应，不看「人声鼎沸」或「极度恐慌」的表面信号，用期权波动率（DVOL/IV）等真金白银博弈出的数据定义市场情绪
- **碎片化操作**——「交易是很系统又连续的事情，不要搞断章取义」，每笔交易有前置推文可追溯

### 宏观推理典范（2026.05 82164 做空 BTC）
```
原油价格 → CPI/PPI 调涨 → 加息预期衍生 → 美债收益率 5%（次贷危机前信号）
                                  → 沃什换帅（鹰派）= 市场下马威 + 新旧两派较量
访华前 → 抛外汇干预汇率 → 拉日元控油价 → 控通胀 → 降低融资成本 → 平和收益率
       → 发美债加深风险偏好
       → 市场预期调停 → 实际没有（预期差）

上述连环相套非独立，均破则单边下跌。
```
**五层连锁推导，缺一不可。这不是技术分析，是宏观侦探工作。**

### 三重博弈论
```
第一层：市场参与者（散户/机构）在交易数据
第二层：大型机构在交易政策
第三层：政策制定者在利用市场实现战略目标
→ 交易员必须站在第三层思考
```

### 极度看重（核心决策层）

| **庄/大资金行为** | 222 | 市场由庄家主导，价格涨跌取决于庄的行为。交易核心是识别庄的动机和成本：OI 大额积累→庄在布局；筹码结构→庄的成本区间；池子深度→庄能控制的价格范围 |

### 高度依赖（战术层）

| 指标 | 权重逻辑 |
|------|------|
| **筹码结构/分布** | 用 @Murphychen888 的筹码分布法计算庄成本区间、支撑/压力、边界条件。DCD 阶梯挂单的每一层都基于筹码结构计算。「止损位 = 当初判断加仓的价格空间的点」 |
| **OI 持仓量** | 庄的仓位地图。OI 大额堆积→庄在布局；OI 骤减→庄撤退。多周期交叉验证 |
| **资金费率** | 拥挤交易信号。极端费率（正或负）+ OI 堆积 = 庄准备反向收割。费率套利也用于对冲决策 |
| **期权数据** | 隐含波动率 (IV) vs 历史波动率 (HV) 的偏差→「大的就要来了」。DVOL 极低→配置 long gamma。期权市场是真金白银博弈出的情绪，比主观感知更准 |
| **盘口深度/价差** | 评估流动性和庄的在场程度。薄深度+高控盘 = 庄可轻易操纵价格 |
| **链上数据** | 巨鲸地址监控、交易所流入流出、聪明钱追踪。确认庄是否在转移筹码 |
| **市值/FDV** | 估值锚定。ASP 盘前 FDV 低于机构投资/kol 轮成本 = 低估；远高于 = 无套利空间 |

### 辅助参考

- **量价/成交量**——仅 26 次提及，量价关系用于过滤缠论信号的噪音
- **EMA/均线系统**——仅 9 次提及，EMA200 是唯一的均线锚，其他周期均线不重要
- **市场情绪**——不依赖主观情绪判断，用期权 DVOL/IV 量化替代

## 3. 交易触发与执行倾向

### 宏观定方向，技术择时机

这是 BTC_Alert 最底层的交易哲学。方向由宏观推理决定（美联储、美债、地缘），时机由缠论/筹码/K 线决定。

### 五大入场模式

**① 盘前定价偏差套利（独门绝活）**
- **集合竞价机制**：利用 OKX 集合竞价的「成交量最大处定价」规则 → 挂单低于/高于竞价价格 → 开盘瞬间成交 → 在其他交易所对冲套利。$ACT 单币套利 10 万刀、$TRUMP 套利 7%。
- **ASP 盘前博弈**：对比 ASP 盘前 FDV 与机构投资成本 / kol 轮成本 → 低于成本 = 低估买入；远高于 = 做空或等待。$GRVT 盘前 2 亿 FDV 做多（机构成本 1.5 亿+），$CHIP 盘前与币安合约价差 28% 套利。
- **跨平台价差**：ASP 开多 + 币安开空 = 锁定价差，等待交割套利。

**② 预期差交易（宏观核心模式）**
- 市场在交易什么？→ 降息预期
- 谁在制造？→ 美联储官员讲话
- 目的是什么？→ 管理市场情绪
- 能否兑现？→ 劳工部和美联储利益出发点不同，可能不符合
- **找到预期差 = 找到交易方向**。

**③ 缠论结构入场**
- 大级别（4H/日线）中枢未破坏 → 趋势延续
- 次级别背驰出现 → 变盘预警
- 三类买卖点交叉验证：大级别中枢支撑 + 次级别底背驰 = 一类买点；回踩中枢不破 = 三类买点
- 结构破坏 → 无条件退出

**④ 恐慌时逆向买入**
- 不是看 Fear&Greed 指数，而是看期权市场的波动率偏差
- DVOL 极低 → 市场过度恐惧 → 配置 long gamma / 抄底
- 「在博弈最激烈的时候再去选择」——不乱抄底，等待多空博弈白热化时站对方向

**⑤ DCD/期权策略建仓**
- DCD（双币宝）：基于筹码结构计算边界条件 → 阶梯挂单 → 折价建仓
- 抄底宝：卖出看跌期权，无论到期价如何都折价获得现货
- 双压期权（Straddle）：同时买 call + put，博弈大波动（FOMC/大选前）

### 真趋势 vs 假信号判别
- **真趋势**：宏观逻辑未被证伪 + 大级别缠论结构完好 + OI 趋势与价格方向一致
- **假信号**：K线短暂突破但宏观逻辑不支持；情绪驱动的急涨急跌无 OI 支撑
- **核心判据**：「结构」是否被破坏——结构未破则趋势延续，结构破坏则逻辑证伪

## 4. 风控与退出策略

### 止损铁律

> **「止损位 = 当初判断加仓的价格空间的点。不止损于恐慌，只止损于逻辑证伪。」**

| 触发条件 | 动作 |
|------|------|
| **宏观逻辑被证伪**（如：美联储鹰转鸽的预期被推翻） | 无条件清仓 |
| **缠论结构破坏**（大级别中枢被跌破/升破） | 结构破坏 = 逻辑证伪 → 止损 |
| **筹码结构破坏**（跌破庄吸筹成本区） | 庄放弃护盘 → 清仓 |
| **OI 崩塌 + 费率异常**（多周期同步暴跌） | 庄离场 → 无条件退出 |
| **情绪恐慌** | **不止损**。恐慌是机会，不是清仓信号 |
