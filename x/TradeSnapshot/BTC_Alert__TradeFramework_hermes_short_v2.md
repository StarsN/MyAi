## 零、进场前置：宏观背景判断（做山寨前必须先过这一关）

BTC_Alert 的核心交易逻辑是**宏观定方向，技术面选时机**。山寨币不是独立存在的——必须先判断当前宏观环境是否支持风险资产。

### 0.1 宏观三层框架

| 层级 | 内容 | 判断问题 |
|------|------|---------|
| 货币政策层 | 美联储利率/缩表/扩表路径 | 流动性在收紧还是放松？ |
| 经济数据层 | CPI/PPI、非农、GDP、美债收益率 | 数据是在验证还是偏离预期？ |
| 地缘政策层 | 关税、战争、外交、大国博弈 | 有没有预期差？ |

> 「一切经济政策的目的总是为了政策服务」——从政策制定者动机出发，而非表面数据 

### 0.2 资产串联链（判断山寨是否在有利位置）

```
原油价格 → 通胀预期 → 美债收益率 → 美元指数 → 风险资产（美股/加密）
 → 黄金（避险对冲）
日元汇率 → 套息交易（carry trade）→ 美股资金面 → 加密联动
```

> 「上述是连环相套非独立，因此上述均破，会带来单边」

**进场条件**：上述链条中各环节方向一致、无断裂 → 可以进场。任一环节出现矛盾 → 等待或轻仓。

### 0.3 不确定性分级（决定仓位大小）

| 级别 | 条件 | 操作 |
|------|------|------|
| 逻辑清晰 | 宏观+对手盘+流动性方向一致 | 满仓/杠杆 |
| 有干扰 | 逻辑成立但单一因素扰动人 | 主仓位不动 |
| 结构风险 | 关键结构位临破或宏观转向信号 | 卸杠杆、对冲保护 |
| 完全不确定 | 多因素矛盾，方向不明 | 持 U 等待击球点 |

> 「动态思考动态修正，这tm才是交易」
>
> 「等待好的击球点」——不做频繁交易，高质量机会才出手

## 一、进场信号清单

### 1.1 对手盘三问（进场前必答）

BTC_Alert 每笔交易前必须回答三个问题。答不出来 → 不进场。

| 问题 | 如何判断 | 出处 |
|------|---------|------|
| 对手盘是谁？ | 散户/庄/套保盘/做市商？看 OI 结构、订单簿深度 | |
| 对手盘的成本在哪？ | 庄多单平均建仓价、空单建仓价、现货收筹区间 | |
| 对手盘的动机是什么？ | 建仓/拉盘爆空/出货/测试机制/左手倒右手 | |

**典型案例**：$PUMP 做多决策
- 盘前合约持仓 = 市值 50% → 只有庄能建这么大
- 庄建仓成本 50-70，池子深度 10M → 能决定 600M 合约 OI 死活
- 结论：庄会拉升爆空 → 做多 

**对手盘反向识别**：
- 项目方回购 = 左手倒右手可以不花成本 → 取消短期拉盘计划 → 平仓 
- 「砸盘取决于庄的格局」——庄有大追求则不会轻易出货 

### 1.2 庄控盘程度判断

BTC_Alert 从多个维度判断庄的控盘程度：

| 维度 | 高控信号 | 低控/分散信号 | 出处 |
|------|---------|-------------|------|
| OI/市值比 | 盘前合约持仓 = 市值 50%+ → 庄建仓 | OI 分散且小额 | |
| 筹码集中度 | 前10地址控筹 95%+ | 无显著集中 | |
| 池子深度 vs OI | 池子深度能覆盖数倍 OI → 庄能控制价格 | 薄盘 → 自己踩自己 | |
| 基差变化速率 | 基差几乎不变 → 极高控盘 | 基差剧烈波动 | |
| 订单簿护盘行为 | 关键价位有 50w+ 买单加厚度 | 无护盘 | |
| 现货收筹 | 下跌过程中 Gate 等所有大量现货买单 | 纯抛售 | |

> 「控盘率到了 90%」的判断：基差变化极小 + 关键价位有大量买单护盘 + 下跌中持续收现货 

### 1.3 基差与溢价信号（2026 新增核心）

BTC_Alert 将币安的基差和溢价指数作为判断多空平仓的核心工具：

- **现货高于合约 + 标记价低于指数价 + 费率非正** → 多单在平仓 
- **基差收敛 + 溢价指数进入费率计算** → 加剧方向性，可以模糊判断主力意图 
- **韩所基差交易逻辑**：基差变化更容易捕捉拉盘前夕，作为监控依据 

**基差判断要点**：
```
合约价格 vs 指数价格偏离 → 进入费率计算（每 5 秒一次）→ 加权平均
→ 如果现货 > 合约 且 标记价 < 指数 且 费率非正 → 模糊判定多单平仓
```

> 「经常操盘的朋友不要忽视：除了基差收敛，币安溢价造成的费率影响也挺麻烦」

### 1.4 流动性三角（进场必验）

| 要素 | 含义 | 多信号 | 空信号 | 出处 |
|------|------|--------|--------|------|
| 池子深度 | 会不会自己踩自己 | 深度充足，对手可被消灭 | 深度不足，自己踩自己 | |
| OI 变化 | 资金在进还是出 | OI 大额积累 → 庄在布局 | OI 萎缩 | |
| 基差/费率 | 多空平衡，有无介入痕迹 | 极负费率 + 无崩盘 | 费率被干预、基差异常 | |

> 「现在的行情下，新币现货交易量没以前的三分之一，合约日交易量过千万的就少。MM 订单簿稀薄得很，这让交易员仓位和操作空间变得很少」

### 1.5 左侧 vs 右侧：不追高、等好价格

- **不追高**：「买在无人问津时」不是指抄底追跌，是等市场冷淡有安全边际时 
- **右侧追需确认趋势**：二段币右侧追，但要确认 MM 还在、控盘还在 
- **事件前建仓，事件后验证**：如 CPI/FOMC 前建预期仓位，数据出来后验证修正 
- **好的建仓价格是等来的，没有宁愿空仓** 

### 1.6 叙事驱动选币

BTC_Alert 的选币逻辑侧重**叙事+对手盘**，而非纯技术面：

- **IP 估值体系**：第二个同类 IP 只有第一个的 20% 市值 → CZ 狗出来平掉 TST 多单 
- **盘前估值锚定**：用融资额、流通比例、控筹程度推算合理 FDV 区间 
- **上新判断**：「alpha+合约的项目，一般高控，出现货可能性很小」→ 利用高控优势拉盘爆空 
- **叙事被创造→资本培养→项目方 fork→赛道割裂→聚合者胜出**

## 二、否决信号（出现任一 → 跳过/观望）

以下为 BTC_Alert 原文明确表达「回避/不碰/退出」态度的信号：

1. **对手盘分析无法得出结论** → 不进场 
2. **流动性太薄，自己踩自己** → 不进场 
3. **项目方回购 = 左手倒右手** → 取消拉盘计划 → 平仓/不做多 
4. **盘前合约无指数价格 = 纯 meme** → 无法用基差逻辑判断 → 不适用正常框架 
5. **开盘市值过高 + 项目方没拉盘动力** → 「币是空气，卖出的 U 才是真金白银」 
6. **逻辑被证伪** → 无条件离场 
7. **偏离预期** → 先平仓修正，不硬扛 
8. **纯反撸项目** → 即使筹码控得紧也不碰

## 三、出场/止盈信号

### 3.1 逻辑证伪出场
- 「不止损于恐慌，只止损于逻辑证伪」
- 「偏离预期的时候，去找自己哪里错了，有没有依据支撑自己错了」

### 3.2 止盈分阶段
- 分批止盈：先出本金，利润继续跑 
- 引用推文中多次提到「TP1」→「继续格局」的分段止盈模式 
- 「事件合约就提前平，或者翻倍平」

### 3.3 动态修正，不设死目标价
- 「从不定死目标价，而是列条件」
- 持仓条件：庄家建仓成本未被破坏、OI 居高不下、爆空有利可图 
- 平仓条件：项目方回购（左手倒右手）、偏离预期、流动性变化、关键结构破位 

### 3.4 盘前套保止盈
- 盘前空单锁利润，等待 TGE 4h 后交割 
- 「永远不要想卖在最高点」——利润够了就出

| 规则 | 内容 | 出处 |
|------|------|------|
| 层级仓位 | 主仓位(6层)长期不动；剩余(4层)用于抄底/加仓/对冲 | |
| 分批下单 | 分 2-3 次下单动态选择合适价格 | |

## 五、做市商/庄行为速查手册

### 5.1 庄的四种行为模式

| 阶段 | 特征 | 出处 |
|------|------|------|
| 建仓期 | OI 缓慢积累 + 价格横盘或微涨 | |
| 拉升/砸盘 | 利用消息面或技术面触发止损/爆仓 | |
| 出货期 | 回购公告/利好消息配合，左手倒右手 | |
| 撤退 | 平稳出货，流动性管理 | |

### 5.2 控盘手法识别

| 手法 | 信号 | 出处 |
|------|------|------|
| 二次操盘 | 洗盘过程中庄买了很多现货 → 成本区间在洗盘低价位 | |
| 控基差做空 | 控期限基差，保证费率恒为负数 → 吸引空头 → OI 变成拉盘燃料 | |
| 质押拉盘 | 嘴撸+质押拉盘+积分套利 → 形成博弈 → 最后反映到 OI 上 | |
| 项目方收现货护盘 | 下跌中 Gate 等所有大量现货买单 → 收筹不低 | |
| 现货砸盘+合约开空 | 「很难实现也赚不到多少」→ 现货砸盘没人接，合约没逻辑 OI | |

### 5.3 妖币/高控币拉盘逻辑

- **高控合约项目动机**：不会上现货（现货要交筹码）→ 通过拉盘爆空赚钱 
- **空踩空回油**：空单 ADL 强制平仓 + 获利空单平仓 带来反弹 
- **做市商与用户对手盘**：链上看到 Wintermute 净卖出 → CEX 提前砸 → OI 无理由放大

## 六、进场决策速查流程（step-by-step）

```
Step 1 → 判断宏观背景（0.1-0.2）
 ├── 资产串联链条完整、方向一致 → 继续
 └── 任一环节断裂或矛盾 → WAIT

Step 2 → 评估不确定性级别（0.3）
 ├── 逻辑清晰 → 可满仓进场
 ├── 有干扰 → 主仓位不动，轻仓试探
 ├── 结构风险 → 卸杠杆，最多小仓位
 └── 完全不确定 → SKIP，持 U 等待

Step 3 → 对手盘三问（1.1）
 ├── 三个问题都能明确回答 → 继续
 └── 任一无法回答 → SKIP

Step 4 → 验证流动性三角（1.4）
 ├── 池子深度充足 + OI 正向 + 基差费率正常 → 继续
 └── 任一薄弱 → 降仓位 或 SKIP

Step 5 → 查否决信号清单（第二章）
 ├── 无命中 → 继续
 └── 任一命中 → SKIP

Step 6 → 基差/溢价确认方向（1.3）
 ├── 现货>合约 + 标记<指数 + 费率非正 → 多单平仓中 → 不做多
 ├── 基差收敛 + 溢价正常 → 做多环境
 └── 基差异常 → 谨慎

Step 7 → 确定入场方式
 ├── 盘前套保逻辑 → 用 aspecta 锁利润等 TGE
 ├── 事件驱动逻辑 → CPI/FOMC 前建仓，后验证修正
 ├── 高控妖币逻辑 → 确认控盘程度后右侧进
 └── 叙事驱动逻辑 → 先估值锚定再等好价格

→ ENTER / WAIT / SKIP
```
