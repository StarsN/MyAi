## 1. 核心交易情境

### 偏好环境
- **震荡行情**——核心舒适区。「周线 MACD 死叉 = 震荡概率高」→ 卖期权吃时间价值（Theta decay）。震荡是期权卖方的朋友。
- **趋势行情（M2 确认后）**——「周线 MACD 金叉 + M2 上行」→ 买期权（Buy Call / Bull Call Spread）。不做裸合约杠杆。
- **低 IV 环境**——隐含波动率低位是逐步建仓看涨期权的窗口。IV ≈ 40% 是 BTC 的历史关键转折区：每次触及此位都伴随重大价格波动。
- **恐慌/错杀**——巴菲特的「捕食者姿态」。「等错杀机会，在市场出现真正的恐慌、好资产被砸到白菜价时入场。」

### 回避环境
- **高 IV 环境裸买期权**——权利金贵，成本高。应反过来卖期权。
- **单边趋势裸做合约**——不提倡裸合约杠杆。期权策略天然带杠杆但亏损有限。
- **看不懂的妖币**——「在'终局'中赚钱并在后续长期投资 BTC/ETH，可能是某种正义。」山寨币只用于短期博弈，长期只认 BTC/ETH。

### 市场状态分类与策略矩阵

| 市场状态 | 判定依据 | 策略 | 核心操作 |
|------|------|------|------|
| **震荡偏多** | 周线 MACD 死叉 + 布林带下轨支撑 | Sell Cash-covered Put | 卖看跌期权收权利金，跌破行权价接货建仓 |
| **震荡偏空** | 周线 MACD 死叉 + 已持仓现货 | Sell Covered Call | 卖看涨期权收权利金，涨破止盈 |
| **宽幅震荡** | IV 偏高 + 明确震荡区间 | Iron Condor（铁鹰） | 同时卖虚值 Put 和 Call，吃双边权利金 |
| **趋势看涨** | 周线 MACD 金叉 + M2 上行 | Bull Call Spread | 买低行权价 Call + 卖高行权价 Call |
| **重大事件前** | OKX 金融日历 + Polymarket 概率异动 | Double-buy Options | 买双边期权博弈波动率放大 |
| **极端恐慌** | 巴菲特指标 > 200% + 恐慌抛售 | 现金储备入场 | 卖深度虚值 Put 或直接现货抄底 |

## 2. 微观指标权重偏好

### 极度看重（核心决策层）

| 指标 | 提及次数 | 权重逻辑 |
|------|:---:|------|
| **隐含波动率 IV** | 40 | **#1 期权交易指标**。IV 是市场对未来波动的定价——低 IV = 买期权便宜；高 IV = 卖期权权利金丰厚。BTC 的 1 个月 ATM IV 在 ~40% 是历史关键转折区。 |
| **M2 / 全球流动性** | 4 | **#1 宏观指标**（低频但权重最高）。全球 M2 数据前移 90 天与 BTC 价格高度拟合。M2 上行 → BTC 中长期看涨。不是每日跟踪，但定调整个季度的方向。 |
| **OI 持仓量** | 36 | 异常 OI 堆积是庄家布局信号。结合 IV 变化判断市场参与者是买期权还是卖期权。 |
| **期权权利金** | 26 | 权利金 APR 是最直观的「震荡市收益标尺」。年化 20-50% APR 卖 put = 合理的被动收入。 |

### 高度依赖（战术层）

| 指标 | 权重逻辑 |
|------|------|
| **周线 MACD** | 大趋势判定唯一指标。金叉 = 趋势，死叉 = 震荡。不做日线以下 MACD——太短太噪。 |
| **布林带 (20,2)** | 震荡区间上下边界。下轨 = 强支撑；下轨 - ATR = 插针极限。价格触及下轨 = Sell Put 的最佳位置。 |
| **ATR (14)** | 波动率估算 + 插针范围计算。布林下轨 - ATR = 极端插针可能到达的位置。 |
| **VPVR POC** | 成交量加权控制点——「市场最认可的价格」。作为 Sell Put 行权价和止盈目标的核心参考。 |
| **ASR-VC 4h** | @cryptopainter 开发的震荡行情支撑/阻力指标。下方蓝色 = 支撑区 → sell put；上方橙色 = 阻力区 → sell call。 |
| **200 日 SMA** | BTC 牛熊分界线。接近时 = 关键决策点；跌破 = 熊市确认（2018、2022 均验证）。 |

### 辅助参考

| 指标 | 备注 |
|------|------|
| **Theta 时间价值** | 期权卖方的朋友——每天都在衰减。周末和节假日的 Theta 衰减是白送的。 |
| **Greeks（Delta/Gamma）** | 进阶期权管理。用于计算对冲比率和风险敞口。 |
| **资金费率** | 辅助判断市场拥挤方向。极端费率 = 反向信号。 |
| **市场情绪** | 不依赖主观感知。用 Polymarket 概率和期权 IV 替代情绪指数。 |
| **威科夫操盘法** | 用于识别大周期 BTC 的吸筹/派发结构。冰线（Ice Line）$84K 是 2026 关键参照。 |

### 基本忽视
- **Taker 买卖比**——不纳入体系（与 Arya、BTC_Alert 一致）
- **RSI / 随机指标**——布林带已覆盖超买超卖
- **新闻/社交媒体情绪**——用 Polymarket 概率代替
- **链上数据**——非核心，偶作参考

## 3. 交易触发与执行倾向

### 核心理念：只做观察，不做预测

> 「"要崩"是预测，"找不到好的买入机会"是观察。他只做观察，不做预测。」
> —— 谈巴菲特的交易哲学，也是 CryptoRounder 自己的信条

不做方向性预测，只根据市场状态选择对应策略。震荡来了就卖期权，趋势来了就买期权，恐慌来了就等错杀。

### 五大入场模式

**① Sell Put 建仓（最常用）**
- 判定：震荡偏多 + 布林下轨支撑 + IV 不低
- 操作：卖出虚值 Put，行权价设在 VPVR POC 或布林下轨附近
- 逻辑：权利金到手 = 打折接货。到期价 > 行权价 → 白赚权利金；到期价 < 行权价 → 以「折后价」接货建仓现货
- 周期：以一周内末日期权为主（Theta 衰减最快）

**② 马丁等额加仓（震荡行情补充）**
- 初始仓位 < 0.1 倍，极度保守
- 优先 sell put → 跌破行权价接多单 → 接多后 sell call
- 价格继续跌 → **等额**加仓（不是等比例，是等金额马丁）
- 以一周内末日期权为主
- 「风险较大，但还是想救一救」——承认风险，不假装

**③ M2 上行 + 低 IV → 布局季度看涨**
- M2 前移 90 天指向 BTC 上行 + IV 低位 → Q3/Q4 逐步建仓看涨期权
- 策略：Bull Call Spread（买低行权价 Call + 卖高行权价 Call），降低成本
- 时间框架：季度级别，不在意短期波动

**④ 恐慌/错杀 → 捕食者姿态入场**
- 触发：巴菲特指标 > 200% + 市场恐慌抛售 + 现金储备充足
- 操作：卖深度虚值 Put（权利金极高但接货概率低）或直接现货抄底
- 「等待错杀机会，以捕食者的姿态入场」

**⑤ Iron Condor 吃双边（宽幅震荡专用）**
- 判定：明确震荡区间 + IV 偏高 + 重大事件已过
- 操作：同时卖虚值 Put 和 Call，构建「铁鹰」
- 到期在区间内 → 双边权利金全收；突破单边 → 损失有限（另一腿权利金对冲）
- 「直觉上此类策略长期应该是 +EV 的」

### Polymarket 作为信息优势
- 概率 = 价格：不需要懂期权，只需要回答「会发生吗？」
- 实时信息：事件推进 → 盘口波动，比新闻更快
- 三层价值：产品心智（低门槛）→ 实时信息（动态概率）→ 社交传播（KOL 带仓位说话）
- 实战应用：美伊冲突概率不乐观 → 降低 BTC 反弹预期仓位

## 4. 风控与退出策略

### 初始仓位铁律：「< 0.1 倍」
极度保守开仓，保留大量现金。「伯克希尔 3970 亿现金储备 = 等待错杀机会的信号。」

### 期权天然风控优势
- **Sell Put 最大亏损** = 行权价 × 数量 - 权利金（相当于限价接货，不会爆仓）
- **Buy Call 最大亏损** = 已付权利金（亏损有限，收益无限）
- **Iron Condor 最大亏损** = 单边突破的损失（另一腿权利金对冲，亏损可控）
- **无需盯盘**：到期自动结算，不爆仓。OKX 高级交易工具支持自动交割。

### 止损 / 退出（与合约交易完全不同的逻辑）

| 触发条件 | 动作 | 逻辑 |
|------|------|------|
| **Sell Put 被行权** | 接货（限价买入现货） | 这是「计划内」的建仓，不是亏损。行权价是提前接受的价格 |
| **Sell Call 被行权** | 被动止盈 | 这是「计划内」的止盈。涨破行权价 → 现货被动卖出 → 锁定利润 |
| **马丁加仓方向错误** | 预设最大加仓次数 | 不加无限仓。总仓位有硬上限 |
| **M2 趋势逆转** | 平掉季度看涨期权 | 逻辑证伪 → 无条件退出 |
| **周线 MACD 死叉** | 从买期权切换为卖期权 | 不反向做空，只调整策略方向 |
| **妖币做空失败** | 严格止损 | $RAVE 教训：「熊市的拉盘意味着主力想利用空头流动性，应多考虑做多机会」 |

### 止盈策略
- **Sell Call 行权 = 被动止盈**——提前接受涨破行权价就卖出的结果
- **Bull Call Spread**——买腿盈利 + 卖腿到期作废 = 利润
- **Iron Condor**——到期在区间内 = 双边权利金全收
- **不追求精确顶部**——「不预测方向」。策略本身定义了止盈，不需要人工判断。
