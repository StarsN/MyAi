# Arya_web3 交易框架

## 一、方向判断

### 1. 叙事驱动选币
- **赛道优先**：RWA、AI、DePIN、Meme、稳定币、L1 公链 → 选赛道再选项目
- **龙头逻辑**：每个赛道只做最确定性的 1-2 个项目
- **叙事验证**：需要同时满足「顶级机构投资 + 豪华团队 + 高 TVL + 顶级上所预期」

### 2. 数据驱动确认
- **合约/现货成交量比 > 3x** → 上涨通道确认，做多信号
- **多空比极端** → 反向操作（多空账户比 < 0.3 做多，> 3 做空）
- **资金费率** → 极度负费率是做多机会
- **OI 变化** → OI 增长 + 价格上行 = 真趋势

### 3. 庄家行为分析
- 识别 MM 洗盘手法："洗完跟车的多单车轻了，一堆人又进去做空了，庄的目的就是爆空单"
- 看准庄的成本区间，在庄的成本附近建仓

## 二、仓位管理

- **杠杆**：5 倍，不超 5 倍
- **止损**：每次必设，无止损不下单
- **分批建仓**：底部区域逐步买入，不是一次满仓
- **止盈**：分阶段出，"鱼尾不参与，没人从头吃到尾"
- **仓位控制**：不重仓单一标的

## 三、入出场规则

### 入场条件
1. 叙事确认 + 数据验证双通过
2. 回调/洗盘时买入，不追高
3. "买在无人问津时" — 市场冷淡时建仓

### 出场条件
1. 分批止盈：先出本金，利润继续跑
2. 逻辑破坏立即离场
3. "未来涨多少都不后悔" — 利润够了就出

## 四、项目筛选体系

### 投研框架（用于 L1/DeFi/DePIN 类项目）
- 项目定位 → 技术架构 → 团队背景 → 生态建设 → 代币经济 → 上所预期
- 特别关注：是否解决真问题、技术壁垒、监管合规

### Meme 代币框架
- IP 价值：马斯克/V神/CZ 相关
- 社区基础：海外社区是否活跃
- 叙事时机：是否踩中热点
- 链上选择：哪个链是 OG 盘

## 五、风控原则

- ⚠️ **不做合约不做杠杆**是 Arya 的核心理念（2024年前），2025 年开始尝试 5 倍合约但始终设止损
- 行情动荡时做好风控和定投
- "挖掘早期便宜筹码（零撸、预挖、场外收），扛住垃圾时间"
- "2:8 定律，赚钱的水远是少数"

## 六、复盘体系

- 每次交易后必复盘
- 复盘格式：操作回顾 → 做的好/不好的点 → 数据验证 → 改进方案
- "只有用心复盘才能进步"

## 七、特殊子方法论

### 新币/土狗交易
- 第一时间找 Solana OG 盘
- 龙头跑出来后马上切换仓位到龙头
- 及时止盈，防止利润回滚

### 稳定币赛道投资
- 看团队背景 + 资本 + 应用市场 + 产业链扩展
- 二级回调后是买入机会
